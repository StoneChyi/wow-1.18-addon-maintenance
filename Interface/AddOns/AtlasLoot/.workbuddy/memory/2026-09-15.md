# 2026-09-15

## AtlasLoot 愿望清单打开崩溃修复（WishList.lua:278）

**报错**：`AceLocale(AtlasLoot):Translation "T1 Sets" does not exist.`

**根因**：`AtlasLoot_CategorizeWishList` 里生成分组标题时，`box`/`parent` 是
`AtlasLoot_TableNamesBoss` 的**外层结构键**（如 "T1 Sets"、"T2 Sets"、"Sets"、
"Crafted Sets - Blacksmithing"）。这些键有些不是 locale 键——locale 里是
"Tier 1 Sets" 而非 "T1 Sets"。代码 `AL[box] or box` 中 `AL[box]` 在缺失键时
由 AceLocale-2.2 的 `__index` 直接 throw，`or box` 兜底永远执行不到。

**修复**：改为用 `AL:HasTranslation(x)` 安全判断（`HasTranslation` 用 `rawget`
绕过 metatable，不抛错），存在翻译才取 `AL[x]`，否则回退原文：

```lua
local boxText = (AL:HasTranslation(box) and AL[box]) or box;
local parentText = (AL:HasTranslation(parent) and AL[parent]) or parent;
table.insert(result, { 0, "INV_Box_01", "=q6="..boxText, "=q0="..parentText });
```

**遗留（未处理，仅提示）**：`TableRegister.lua` 的 "T1 Sets"/"T2 Sets"/"T3 Sets"/
"ZG Sets"/"AQ20 Sets"/"AQ40 Sets"/"D1/2 Sets"/"Crafted Sets - Xxx" 等外层键与
locale 键（"Tier 1 Sets"/"ZG Class Sets"…）不一致，中文客户端下这些分组标题会
回退显示英文原文。若要全中文，需统一这两套键（或给这些结构键补 locale 条目）。

**关键知识点**：
- AceLocale-2.2 的 `AL[missing]` 会 **throw**（不是返回 nil），不能靠 `AL[k] or k`
  兜底；安全查询用 `AL:HasTranslation(k)`（返回 true/nil）。
- `AtlasLoot_TableNamesBoss` 外层键 = 英文分组名（多数是 locale 键，但 Sets 段
  用了 "T1 Sets" 这类非 locale 键）；内层值 = `{ AL[...] 显示名, 数据源 }`。

## 补 locale 键（方案 1，接上条遗留）

给 `AtlasLoot_TableNamesBoss` 的缺 locale 结构键补全，让中文愿望清单分组标题
正常显示中文（不依赖英文回退）。

**修改文件与键**：
- `Locale/locale.en.lua`（base，`= true`）补 9 键：`T1 Sets`/`T2 Sets`/`T3 Sets`/
  `ZG Sets`/`AQ20 Sets`/`AQ40 Sets`/`D1/2 Sets`/`WorldBosses`/`Professions`。
  （`Crafted Sets - Blacksmithing/Leatherworking/Tailoring` 在 en 里**本就有**。）
- `Locale/locale.cn.lua`（中文）补 12 键，插到 `--套装/收藏` 块末尾：
  `AQ20 Sets`=安其拉废墟套装、`AQ40 Sets`=安其拉神殿套装、
  `Crafted Sets - Blacksmithing`=锻造套装、`...-Leatherworking`=制皮套装、
  `...-Tailoring`=裁缝套装、`D1/2 Sets`=地下城套装、`Professions`=专业技能、
  `T1/T2/T3 Sets`=T1/T2/T3套装、`WorldBosses`=世界首领、`ZG Sets`=祖尔格拉布套装。

**AceLocale 约束（重要，以后补键务必遵守）**：
- base 键值 `true` 会在注册时被替换为键名（en 里 `["X"]=true` → 显示英文原文）。
- 非 base locale 的每个键**必须已存在于 base**，否则报 "Improper translation exists"；
  值**不能是 `true`**，否则报 "Can only accept true on base locale"。
- 非 base locale 缺某键时，访问 `AL[key]` 会走 fallback 链
  `当前locale → base(en) → prototype(throw)`，即**只要 en 有键，其他语言缺了也
  不会崩，只会显示英文原文**。所以本次只改了 en+cn，de/es/fr/kr/ru/tw 未动（会
  回退英文，可接受）。

**结构键 vs 显示名不一致（数据层面遗留）**：`TableRegister.lua` 用 "T1 Sets" 等
作 `AtlasLoot_TableNamesBoss` 外层键，而菜单显示用 "Tier 1 Sets"。本次靠补 locale
键把两者都指向同一中文，但英文客户端下 wishlist 分组标题会显示 "T1 Sets"（结构键原文）
而菜单显示 "Tier 1 Sets"，仍不一致——如需彻底统一要改 TableRegister 的外层键（牵扯
`GetLootTableParent` 返回值和菜单导航，暂未动）。
