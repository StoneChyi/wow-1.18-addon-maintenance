# 2026-08-20

## S_ChatBar 新增「药」按钮
- 在聊天快捷键栏新增一个 "药" 按钮，点击打开 CatPotion 药剂窗口。
- 实现方式（沿用插件按钮模式）：`S_ChatBarDB.buttons.CatPotion`、`BUTTON_ORDER` 加入 `"CatPotion"`，`ChannelCatPotion_OnClick` 调 `CatPotionAddon.TogglePotionWindow()`。
- CatPotion 窗口真名：`CatPotionWindow`（Window.lua:18 创建），全局表 `CatPotionAddon`，`TogglePotionWindow()` 负责显隐切换。
- 行为：PLAYER_LOGIN 时按钮随 `IsAddOnLoaded("CatPotion")` 自动启用；未加载 CatPotion 时按钮隐藏且不在配置菜单出现。
