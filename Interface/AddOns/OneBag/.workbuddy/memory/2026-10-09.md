## OneBag 标题栏侧栏开关按钮补鼠标提示
- 用户用框架检查器报 `OneBagFrameBagButton 没有鼠标提示`。
- 根因：OneBag.xml 中模板 `$parentBagButton`（侧栏开合小按钮，OneBagFrame/OneBankFrame/OneRingFrame 共用）只有 OnClick/OnLoad，从未定义 OnEnter/OnLeave。
- 修复：模板 Scripts 内补 OnEnter（GameTooltip SetOwner ANCHOR_TOPRIGHT）+ OnLeave（GameTooltip:Hide()），一次修改三个窗口同时生效。OneViewFrame 走 OneBagBaseFrameTemplate 不含此按钮。
- 提示文案按用户意见定为"更换背包"（初版"切换侧栏显示"被替换）。
- 备份：backup/OneBag_20261009_1525.xml；XML 用 Python minidom 校验通过。
