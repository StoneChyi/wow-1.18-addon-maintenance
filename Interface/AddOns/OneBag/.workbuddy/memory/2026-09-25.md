# 2026-09-25

## Shift 拆分失效修复（OneBag 回归）
用户反馈背包物品按住 Shift 不能拆分。根因：2026-09-23 把 4 处 `SetItemButtonCount` 换成统一出口 `OneBag_SetSlotCount` 时，丢掉了 vanilla `SetItemButtonCount` 的一个副作用——它会写 `button.count`（已对照 1.12 FrameXML 原版源码确认：ItemButtonTemplate.lua 的 SetItemButtonCount 内 `button.count = count`）。而 Shift+点击拆分链路是：OneBag 按钮自定义 OnClick（OneBag.lua:2724）→ `ContainerFrameItemButton_OnClick(arg1)` → Shift 分支 `OpenStackSplitFrame(this.count, this, "BOTTOMRIGHT", "TOPRIGHT")`（ContainerFrame.lua 原版）→ `this.count` 为 nil → 拆分窗口不弹。

### 改动
- OneBag.lua `OneBag_SetSlotCount`：入口处补 `button.count = rawCount`（nil→0；负数→1，SuperWoW 负充能编码下油类不堆叠按 1 瓶计）。
- 备份 backup/20260925-*，luaparse OK。

**通用教训（已记入跨项目记忆）**：替换 vanilla 全局 SetItemButton* 系列函数时，注意 `button.count` / `button.numInStock` / `hasItem` 等字段副作用——其它系统（拆分窗口、AutoStore 等）依赖这些字段。
