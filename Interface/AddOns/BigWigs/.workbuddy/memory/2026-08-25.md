- **新增 CHAT_MSG_SYSTEM 监听**：检测系统提示"个人锁定权限"消息（中英文模式匹配），自动标记 Boss 为「CD 中，时间不明」
- **双存储表设计**：`worldBossKills`（精确 time() 时间戳）+ `worldBossLocked`（布尔，仅知在 CD）

  - `[CD]` 橙色 = 冷却中（有精确时间，显示倒计时）
  - `[CD?]` 橙色 = 冷却中/时间不明（仅从锁定提示检测到）

- **锁定消息模式用 `.*` 宽容标点差异**（中文逗号/句号/感叹号兼容）
- **修正触发逻辑**：锁定提示是「击杀后系统判定已有CD才弹」，不是靠近尸体。改用 `lastKill` 缓存（name/time/prev），若击杀后 5 秒内弹锁定提示 → 撤销刚写的时间，恢复旧值；若旧值本来为 nil → 标记 `locked`（时间不明）

## UI 面板 bug 修复
- **ShowPanel 顺序 bug**：原 `ShowPanel` 先 `RefreshPanel()` 再 `panel:Show()`，而 `RefreshPanel` 开头有 `if not IsShown() then return end` → 打开面板时渲染被跳过，显示空白。改为先 Show 再 Refresh。
- **1.12 按钮需显式 EnableMouse + RegisterForClicks**：`CreateFrame("Button")` 默认不接收点击，关闭/刷新按钮都补上 `EnableMouse(true)` + `RegisterForClicks("LeftButtonUp")`。
- **刷新按钮 OnClick 用模块全名**：原 `self:RefreshPanel()` 闭包里 self 可能解析失败导致静默报错（关闭按钮用局部 `panel` 故正常）。改为 `BigWigsWorldBossCooldown:RefreshPanel()`。
- **刷新文字反馈**：点击后按钮文字短暂变「已刷新!」1 秒（OnUpdate + GetTime 计时），确认按钮有响应。
- 空状态提示误写「靠近尸体自动检测」，已改为「击杀世界Boss后自动记录」。
