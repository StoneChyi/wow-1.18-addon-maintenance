
## 2026-08-28 修复 Babble-Spell "Blessing of Protection" 报错
- 游戏内刷屏 `ERROR: Babble-Spell-2.2: Translation "Blessing of Protection" does not exist.`
- 根因（部分）：Babble-Spell zhCN 表把 BoP 写成了零售版名"保护之手"，与 Turtle/香草中文客户端实际名"保护祝福"不符；CommonAuras zhCN 的 bop_trigger/bop_fades 还是英文战斗日志文本，中文客户端匹配不到。
- 改动：
  1. `!Libs\Babble\Babble-Spell-2.2\Babble-Spell-2.2.lua` zhCN：`["Blessing of Protection"] = "保护祝福"`（原"保护之手"）
  2. `BigWigs\Plugins\CommonAuras.lua` zhCN 表：`bop_trigger = "保护祝福"`、`bop_fades = "保护祝福"`（模糊匹配，gain/fade 事件分开所以不会互串）
- 备份：`BigWigs\backup\CommonAuras_20260828_231026.lua`、`!Libs\Babble\Babble-Spell-2.2\backup\Babble-Spell-2.2_20260828_231026.lua`
- 未解之谜：错误消息是英文 key 的 forward lookup 报错，但全代码搜不到 `BS["Blessing of Protection"]` 直接调用；待用户游戏内 /reload 后回归测试，若仍刷屏需定位动态查找来源。
- 追加：BoP 双名兼容。zhCN bop_trigger/bop_fades 改为模式串 `保护[祝之][福手]`（同时匹配 保护祝福/保护之手）；计时条建/删改用 `L["Blessing of Protection"]`（=保护祝福）作干净标题，RemoveBar 与 Bar 键名保持一致。注意：AceLocale-2.2 非 base 语言表的 key 必须存在于 enUS base 表，否则加载时报 "Improper translation exists"。备份 CommonAuras_20260828_231744.lua。
