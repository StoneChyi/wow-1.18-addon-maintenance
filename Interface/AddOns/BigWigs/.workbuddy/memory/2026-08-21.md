## 新增 BigWigs boss 模块：提里奥克 (Trioch)
- 文件：`Raids/TMH/Trioch.lua`，并在 `BigWigs.toc` 注册（本 fork 的 .toc 逐文件列出模块，必须手动加，否则不加载）。
- 归属：木吼要塞 = 木喉要塞 (Timbermaw Hold / TMH) 自定义团本，沿用 TMH 的 `module.zonename` 表 + `enabletrigger = "提里奥克"`。
- 三技能：烈焰之颅（方向性锥形，注意头部朝向，两方向分别预警）、腐蚀之颅（标记2人→脚下软泥集火→毒池跑开，定时条方案）、冰锥（标记2人→集合分担）。
- 约定要点：团本标记用 `GetAvailableRaidMark(nil,true)` + `SetRaidTargetForPlayer` + `RestorePreviousRaidTargetForPlayer`（还原到改之前的 mark，含 0 即清除）；自标在 RAID_BOSS_EMOTE 里显示「你」，需 resolveName 转成本地名；标记类用本地解析（非 sync）以免不同客户端分配不同 mark 冲突；纯计时条才用 sync + `BigWigs_RecvSync`。
- timer 均为占位值，需进本实测 CD 后校准：flameCast/flame/corrosion/oozeSlime(集火窗口)/oozePoison(毒池窗口)/iceLance/iceLanceHit。
- 校验：括号配平；L[]/icon/color/timer/syncName 引用均有定义；未用 1.12 不支持的 string.match/gmatch/!=/ //（`~=` 正确）。
- 若后续提供「软毒死亡」「毒池生成」的战斗日志原文，可把腐蚀之颅改为精确检测（标记自动清除、毒池警告精准触发）。

## 提里奥克 腐蚀之颅：精确检测软泥死亡
- 用户给了真实名称：软泥怪 = **蠕动的异质**，毒池 = **毒害之云**。
- 改动：`OnEnable` 注册 `CHAT_MSG_COMBAT_HOSTILE_DEATH`，新增 `module:CHAT_MSG_COMBAT_HOSTILE_DEATH` handler：
  - 先 `BigWigs:CheckForBossDeath(msg, self)` 保留核心 boss 击杀检测（覆盖默认 handler 时必须手动调，参考 Ayamiss.lua 写法）。
  - 用 `string.find(msg, "蠕动的异质")` 检测软泥死亡，触发 `OozeDead()`（毒池跑开）。
- `OozeDead` 改为幂等（`oozeDeadFired` 守卫，只触发一次毒池阶段），并 `CancelScheduledEvent("TriochOozeDead")` 取消定时兜底；`OnSetup/OnEngage/OnDisengage` 重置 `oozeDeadFired`。
- 文案已全部改用「蠕动的异质」「毒害之云」。定时条 oozeSlime 仅作击杀窗口兜底。

## 提里奥克：boss 全名 = 吞噬者提里奥克（关键约定）
- **坑**：本 fork 的 `CheckForEngage` 用 `UnitName("target") == module.enabletrigger` 做**精确**匹配（Core.lua:723），且 `module:ToString()` 返回的是 `ModuleDeclaration` 第一个参数（完整 boss 名），`CheckForBossDeath` 的 `UNITDIESOTHER` 分支也靠它匹配击杀。
- 所以 TMH boss 模块必须：`BigWigs:ModuleDeclaration("完整boss名", "Timbermaw Hold")` + `module.enabletrigger = module.translatedName`（参考 Karrsh/Perotharn 写法）。
- 之前误写成 `enabletrigger = "提里奥克"` / `translatedName = "提里奥克"`，真实单位名是「吞噬者提里奥克」，会导致模块**永不启用** + 击杀不检测。已改为全名。
- 战斗日志触发器仍可保留「提里奥克」子串（"吞噬者提里奥克…" 内含该子串，两种写法都能命中），无需改成全名。
