## Comm.lua 小队 sync 修复（CommonAuras 小队提醒）
- 问题：CommonAuras 提醒（盾墙/破釜沉舟/恐惧结界/挑战怒吼/虫洞/橙子/灵魂之井等）在 5 人小队不显示。
- 根因：`Plugins\Comm.lua` 的 `BigWigs_SendSync` 固定 `SendAddonMessage("BigWigs", msg, "RAID")`，RAID 频道在非团队（纯小队）时无效，sync 发不出去；接收端也只认 type=="RAID"。
- 修复（通用，所有模块受益）：
  - 发送端按队伍形态选频道：`GetNumRaidMembers() > 0` → RAID；否则 `GetNumPartyMembers() > 0` → PARTY；单人只本机回环（不发网络）。
  - 接收端 `CHAT_MSG_ADDON` 放行 type 为 RAID **或** PARTY。
  - 本机回环仍传 "RAID" type（保证 Comm 自身 handler 收到）。
- 备份：`backup/Comm.lua.20260928_1918.bak`；luaparse 校验通过。
- 注意：改完后 grep 验证过落盘；客户端若开着，警惕回写覆盖（历史踩坑）。

## CommonAuras 新增「奴役恶魔」追踪

- 实现（Plugins\CommonAuras.lua，参照盾墙/灵魂连接模式）：
  - 触发：仅术士生效，三通道兜底——CHAT_MSG_SPELL_SELF_DAMAGE、CHAT_MSG_SPELL_SELF_BUFF（顶部挂钩 CheckEnslaveCast）、CHAT_MSG_SPELL_PERIODIC_PET_BUFFS（恶魔名直接取 UnitName("pet")）。trigger 用稳定子串「施放了奴役恶魔」/「获得了奴役恶魔的效果」。
