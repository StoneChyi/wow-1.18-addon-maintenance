# YGB_OTAlarm 插件

## 插件名称
YGB_OTAlarm - 烟锅巴OT提醒器

## 版本
2.1

## 作者
烟锅巴

## 功能描述
- 监控玩家的仇恨值，当仇恨超过设定阈值时自动施放变身法术
- 可自定义报警阈值（10%-100%）
- 可设置自定义变身法术
- 实时显示仇恨数据和调试信息

## 使用方法
1. 输入命令 `/ygbot` 打开插件面板
2. 设置报警阈值（滑动条）
3. 输入变身法术名称并点击"设置"按钮
4. 插件会在战斗中自动监控仇恨值，当超过阈值时自动施放变身法术

## 依赖
- TWT插件（用于获取仇恨数据）

## 注意事项
- 确保你已经学会了设置的变身法术
- 插件在战斗中每0.5秒检查一次仇恨值
- 当仇恨超过阈值且满足施法条件时，插件会自动施放变身法术
