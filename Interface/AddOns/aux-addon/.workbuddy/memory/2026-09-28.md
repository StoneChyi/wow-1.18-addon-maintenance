## aux-addon ChatThrottleLib 报错 "Invalid escape code in chat message"
- 截图报错：`libs\ChatThrottleLib.lua:254: Invalid escape code in chat message` 反复刷屏。
- 根因：1.12 客户端对 `SendChatMessage` 消息中的字节 124（`|`）硬编码抛此错。报错行 254 是 CTL 钩子的透传调用，说明非法内容来自**其他插件**经全局 `SendChatMessage` 发送（aux 自身的 `AuxData,itemID:suffixID,价格` 消息干净无 `|`）。
- 修复（`libs/ChatThrottleLib.lua` Hook_SendChatMessage）：pcall 包裹原生调用拦截报错，5 秒节流打印消息内容（截断 60 字符）+ `debugstack(3,1,0)` 调用来源，便于定位元凶插件。
- 备份：`backup/ChatThrottleLib_20260928_200710.lua`；luaparse 校验通过。
- 待办：下次进游戏触发时看 "CTL: caller" 行，找出真正发 `|` 内容的插件（候选：XyTracker wishlist 同步、聊天广播类）。
