## 修复 TrainerSkills 主窗口不可拖动
- 根因：TrainerSkills.xml 主窗体只声明 `movable="true"`，但无 `<TitleRegion>` 也无 `OnDragStart/OnDragStop` 脚本，1.12 下实际拖不动（对比配置窗口有 TitleRegion 所以能拖）。
- 修在皮肤里（不动第三方插件本体）：`SetMovable(true)` + `EnableMouse(true)` + `RegisterForDrag("LeftButton")` + SetScript 拖拽启停（闭包直引全局，规避 1.12 SetScript 不传 self 陷阱）+ `SetClampedToScreen(true)` 判空保护。luaparse 校验通过。
