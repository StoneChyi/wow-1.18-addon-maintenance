# 净界驱散 · PureDispel 2.1

基于何雨欣 / hyx 的个人维护版本。个人修改与维护：**StoneChyi & Codex**。保留原作者及原有适用许可，不将第三方作品整体归为维护者所有。

安装目录继续使用 `hyx`，保存变量仍为 `xinDB`。升级时保留原有设置；加载顺序为 `XinDispel.lua`、`RaidData.lua`、`PureDispelUI.lua`、`Debug.lua`。原 `hyx.lua` 保留作来源参考，不再加载其旧界面。pfUI 为可选依赖；可用时采用其字体、配色和边框，缺失时使用内置后备。

## 操作

- 聊天栏“驱”：左键显示/隐藏统一驱散窗口，右键始终打开设置。
- 列表：上方可驱散、下方暂不可驱散，各自固定高度并独立滚动。Shift + 滚轮跳到本区首尾；空区保留位置并留白，不显示“暂无目标”。
- 队员行：左键驱散，右键目标菜单，中键选中目标。设置中可启用“右键也驱散”，此时 Shift + 右键打开菜单。
- 标题栏：解锁后可拖动；锁定不影响点击或滚动。关闭主窗口会暂停列表扫描，重新打开立即刷新。
- `/puredispel`、`/pd`、`/xin`、`/hyx`、`/xinload`：打开设置；`status` 显示能力和扫描计数，`top` 回到两区首行，`show` / `hide` / `toggle` 控制主窗口。

背景和边框不透明度单独调整，0% 为完全透明、100% 为不透明；文字和图标不随背景一起变淡。字体默认跟随 pfUI，加载失败时保留内置字体。主界面最多复用20个目标行，数据仍覆盖完整队伍/团队；已有行数设置保留，新配置默认6+3行。屏幕不足时收敛实际可见行数，保证两区可见。

设置分为“布局”和“外观”两页。布局页可调宽度180–600、高度220–900；窄窗口采用紧凑标题和按钮，背景高度也受屏幕和两区最小行高约束。自定义高度按上下行数比例分配空间，能显示的行数以实际空间为准。默认按行数自动匹配高度；修改上下行数，或点击“按上下行数匹配高度”，均恢复自动匹配。

## 调试与诊断

输入 `/pd debug`，或在设置中点击“调试 / 诊断”。面板手动刷新当前技能识别、接口存在状态、名单数量、扫描/读名计数、实际宽高、可见行数与透明度。点击“全选复制”后按 Ctrl+C 可复制报告；这不会自动写文件或发送数据。

详细日志默认关闭，无新增定时器、逐帧采样或聊天输出。主动启用后，只在内存保留最近60条驱散/名单/减益规则操作，重载后重置；报告与日志省略角色姓名、服务器、账号和未知错误文本。接口存在不代表DLL加载或实际施法已经验证。

## 优先、忽略与规则

右键菜单可直接设置本队优先、本队忽略、清除本队规则，也可进入当前减益规则或名单管理。底部“已忽略 N”可找回目标，名单页支持按来源恢复、输入姓名以及本队/长期作用范围；“撤销上次操作”撤回最近一项名单或自定义减益规则修改。

同角色同队重载保留本队规则；规则绑定角色/服务器，确认离队后清除并作废撤销。正常增减员或小队转团队保留。长期规则跨队伍保留，沿用原账号级存储语义。优先不能悄悄解除忽略，也不能绕过职业能力、距离或整人禁驱规则。被忽略的人离开两区操作列表，可从名单页恢复。

同角色离线期间更换队伍缺少可靠队伍标识，无法保证自动判断这种边界；需要时在名单管理清除本队规则。

- **不以此减益提示驱散**：忽略该减益的推荐，其他减益仍可能触发驱散，法术可能顺带移除它。
- **有此减益时跳过整个人**：该减益存在期间，插件不对目标施放驱散。
- **移除自定义规则**：恢复由原团本/职业规则决定；团本规则在完整手册中查看、修改，不会被清除自定义规则一并删除。

完整原手册数据保留，支持直接选择团本、滚动查看技能与详情，编辑类型规则及九职业过滤。手册是原作者参考资料，机制以当前服务器实际表现为准。

## 能力和验证范围

按实际技能书识别骑士、牧师、德鲁伊、法师、萨满，以及术士当前宠物的友方驱散能力；未学习或当前职业没有对应能力时不生成可驱散目标。术士从宠物位置检查。UnitXP / SuperWoW / Nampower 可用时使用已有接口；本次不替换 DLL。未知减益名字不伪造候选，点击时重新核对实际目标、减益、规则与技能。

45组严格字体/API模拟行为检查与4个加载文件的真实Lua5.0语法检查通过。2.0版固定40人模拟中，100次不变扫描的减益读名从32000次降至4000次，可见文字/贴图重复写入归零；这些是模拟调用次数，不代表实际帧率、CPU或内存降幅。本轮实际排版、滚轮、报告复制、服务端施法及真实资源占用仍待游戏验收。
