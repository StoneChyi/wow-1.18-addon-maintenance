# 2026-08-21

## SpecialTalent UI 修复
- 修复翻页按钮文字与功能相反：原 `SpecialTalentUI.xml` 中 NextButton*(上页/上一页) 绑定 `NextPlan()`(+1)、PreviousButton*(下页/下一页) 绑定 `PreviousPlan()`(-1)。改为文字与语义统一（Next→下一页→NextPlan，Previous→上一页→PreviousPlan）。
- 修复只能拖头像移动框体、标题栏不能拖：在 `SpecialTalentFrame_OnLoad` 增加 `this:RegisterForDrag("LeftButton")`，并在 `SpecialTalentFrame` 的 `<Scripts>` 增加 `OnDragStart`/`OnDragStop`（与头像 DragButton 行为一致，复用 `SpecialTalentFrame_OnDrag()` 记录位置）。
- 修复 ESC 不能关闭框体：根因是拖动后 `SpecialTalentFrame_CheckDragged` 把 `UIPanelWindows["SpecialTalentFrame"]` 置 nil 并切到 `ToggleDragged`（直接用 `:Show()/:Hide()`），导致框体脱离 UIPanels 栈、ESC 的 CloseWindows 无法关闭。改为：拖动后 `SetUserPlaced(1)`（ShowUIPanel 不会覆盖用户位置），保留 UIPanelWindows 注册、Toggle 统一走 `SpecialTalentFrame_ToggleFrame`（ShowUIPanel/HideUIPanel），从而进入 UIPanels 栈、ESC 可关。
- 修复拖动后再次打开不保存位置：上一条为 ESC 把开关改回 ShowUIPanel，但 ShowUIPanel 打开时按 area 重排框体、覆盖拖动位置，且 CheckDragged 只在加载/拖动时调用、打开时不恢复。改为在 OnShow 开头用保存的 frameLeft/frameTop 主动 SetPoint 恢复（覆盖 ShowUIPanel 默认定位）。SpecialTalentFrameSaved 已在 toc 声明为 SavedVariables，重载也保持。
