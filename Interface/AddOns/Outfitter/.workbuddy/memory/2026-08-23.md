# 2026-08-23

## Outfitter 副本禁用(InstDisabled)判定修复
- 根因：`Outfitter_InInstanceZone()` 原实现查 `Outfitter_cZoneSpecialIDMap[gOutfitter_CurrentZone]`，只硬编码了 6 个区(AQ20/AQ40/ZG/ES/BM/K40)标为 "Instance"，其余经典/乌龟服副本(死矿/黑石/厄运/斯坦索姆/熔火/黑翼/纳克萨玛斯等)均不在表内 → 副本禁用对这些副本不生效。
- 修复(Outfitter.lua:4521)：改为用游戏自带 `IsInInstance()` API，仅认 `party`/`raid` 两种类型(战场有独立 BGDisabled 不覆盖)。影响面仅 `Outfitter.lua:4431` 一处禁用判定；独立的 "Instance" 特殊套装自动穿路径为死代码、不受影响。
- 边角：仅阻止"在副本内自动穿上"InstDisabled 套装；进副本前已穿上的不会强制脱下(原设计即如此)。如需进本强制脱下可再加。
