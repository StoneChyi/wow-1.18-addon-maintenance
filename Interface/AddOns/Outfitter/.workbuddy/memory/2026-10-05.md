## QuickSwap 拖动区鼠标提示
- 需求：悬停在快捷换装面板「可移动区域」时显示提示（左键拖动移动）。
- 实现：`OutfitterQuickSwap_Initialize` 内加局部 `BarTipOnEnter/BarTipOnLeave`，挂到三处拖动面：分栏1 标题栏 vTitleBar、分栏1 栏位条 vBar、分栏2 栏位条 vBar2 的 OnEnter/OnLeave。
- 内容：普通态 = "快速换装 / 按住鼠标左键拖动移动 / 滚轮缩放　右键打开菜单"；Locked 态 = "快速换装（已锁定）/ 右键打开菜单可解锁拖动/缩放"。`GameTooltip:SetOwner(this, "ANCHOR_TOP")` + ClearLines + AddLine。
- 物品按钮自带 OnEnter 会拦截悬停，提示只出现在按钮间隙（即真正可拖动的空白处）。
- luaparse 校验通过。

## QuickSwap 默认落点改为 BCS 属性面板上方
- 用户实报：旧默认右下角落点 (1122.53, 275.53) 与 pfUI 目标头像重叠 → 默认改锚 BCS 属性悬浮窗正上方。
- BCS 悬浮窗无全局名字，走全局 `BCS.PropertiesPanel.frame` 引用（BCS_PropertiesPanel.lua:159）；默认 CENTER,350,-100，拖过后存 BCSConfig.PropertiesPanel。
- `OutfitterQuickSwap_ApplyDefaultPosition`：有 BCS → `SetPoint("BOTTOMLEFT", vBcsPanel, "TOPLEFT", 0, 6)`（相对锚定，未拖动期间贴着 BCS 走；拖过被 ReanchorFrame 重锚回 UIParent 即解耦）；无 BCS → 退回旧固定落点。
- 旧存档迁移：LoadSettings 里存档 X/Y ≈ 旧默认值（±1）视为"从未拖过"→ 重新 ApplyDefaultPosition；真拖过的位置不动。
- LoadSettings 在 PLAYER_ENTERING_WORLD 触发，此时 BCS 已加载定位完，引用时序安全。
- luaparse 校验通过。
