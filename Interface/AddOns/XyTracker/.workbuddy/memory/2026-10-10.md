
## 许愿权定向移交功能（XyTracker.lua）
- 需求：许愿权可指定移交给团队某人；真实团长(rank 2)权限更高，别人持有许愿权时团长也可随时指定。
- 实现（备份 backup/XyTracker_20261010_195708_pre_transfer.lua）：
  1. 新增 UnitPopupButtons["XY_TRANSFER"]="移交许愿权"（L163）；
  2. XYT_ApplyTransferButton(menu)（L399）控制可见性：IsLeader 或 rank==2；挂到 PARTY/RAID/RAID_PLAYER 菜单（XyTracker_RegisterRightClickMenuButtons L346）；
  3. ple_unitpopup1 增加 XY_TRANSFER 分支 → XyTracker_ConfirmTransfer(name) → StaticPopup 确认 → XyTracker_DoTransfer(target)（L3367-3418）：发 XY_TRANSFER addon 消息 + 团队喊话 + 本地让位；
  4. OnEvent 新增 XY_TRANSFER 处理（L3623）：ShouldAcceptTransfer 校验发起者（持有者或 rank2）；目标置 IsLeader=true、XyInProgress=true（恢复录入）、显示放弃/停止按钮；非目标让位并认领新 LeaderName。
- 语法校验：新增段 luaparse 通过；全文件报 [779] break; 为存量代码误报（备份同报，Turtle Lua 5.0 语法允许 laststat 后分号），非本次引入。
- 待游戏内实测：发起移交/接收移交/团长越权指定/移交后许愿录入连续性。

## 修复：移交许愿权后非持有者仍显示团长按钮
- 实测：移交给最爱莉后，最爱煜界面仍有开始/重置/初始化DKP等按钮且能点开始。
- 根因：DoTransfer 与 XY_TRANSFER 事件非目标分支都调用了 EnableLeaderOperation()，把整套团长按钮恢复了（普通成员也被恢复成团长 UI）。
- 修复（备份 backup/XyTracker_20261010_195708_pre_transfer.lua 之后另有 _pre_transfer_ui_fix）：两处均去掉 EnableLeaderOperation()，改为 DisableLeaderOperation()（原持有者）+ 显式 Hide Relinquish/Start/Stop 三按钮，只有被指定目标走完整团长 UI（EnableLeaderOperation + XyInProgress=true）。
- luaparse 分段校验通过。
- 备注：团长若想自己拿回许愿权，目前需当前持有者右键团长移交（SELF 自身右键菜单未挂 XY_TRANSFER，如需团长右键自己指定自己，后续可加 SELF 菜单）。
