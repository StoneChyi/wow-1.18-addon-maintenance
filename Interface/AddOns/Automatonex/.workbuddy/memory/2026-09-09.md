## 修复 AceLocale 报错（zhCN/enUS key 不对称）
- 现象：加载即报 `AceLocale(Automaton_QuestItemBar): Improper translation exists`（QuestItemBar.lua:28，zhCN 注册行）。
- 根因：GUI 输入框新增的 4 个 key 只加进了 zhCN 块，没加 enUS 块。**AceLocale-2.2 在注册语言时会双向比对所有已注册语言表，key 集合不一致即报 "Improper translation exists"**——以后给任何 Automatonex 模块加 L key，必须 enUS/zhCN 两块同时加。
- 修复：4 个 key 补进 enUS（备份 `backup/QuestItemBar_20260909_114450.lua`）；核对两块各 20 key 对称 + luaparse 语法通过。

## 环境经验：Git Bash 下 node.exe 的 NODE_PATH
- 从 Git Bash 调 Windows 版 node.exe 时，`NODE_PATH=$HOME/...`（/c/... 风格）**不会被识别**，模块解析失败报 MODULE_NOT_FOUND。必须 `NODE_PATH="$(cygpath -w ...)"` 转成 Windows 路径。luaparse 本身没被清理，只是路径问题。
