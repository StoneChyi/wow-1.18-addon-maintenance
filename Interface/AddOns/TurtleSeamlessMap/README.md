# Turtle Seamless Map 0.6.0

独立的乌龟服 1.12 世界地图插件。接管 M 和常见原地图入口，可独立运行，提供 ModernMapMarkers、Atlas、pfQuest 的明确适配。世界、两大陆、53 个室外区域和七城共用原坐标画布；副本图页不进入浏览。

默认真实地形详情＋原版世界总览。“地图样式”可切换真实地形／手绘、原版世界／连续地图，并保存。地形模式的“城市细节”控制七城高清近景，手绘模式仍控制原城市插画；旧开关设置保留。小窗口工具栏两行，地图保持原比例。

## 0.6.0 的画面变化

- 两大陆图集最高密度由 16 提至 32，线性采样精度两倍、同范围像素四倍；以真实地形材质的细节补充原生小地图，保留原有地标与坐标。室外小建筑等仍可能受到原始预渲染素材的分辨率限制。
- 五座地表主城使用本机 ADT／WMO／M2 放置、几何和材质重新绘制静态近景，图集最高密度 64。保留原生植被背景，不额外绘制遮挡街道的树冠；亮度参考原生小地图。铁炉堡、幽暗城直接由原生房间像素生成 96 密度近景，保留轮廓及岩壁空隙。
- 希利苏斯—安其拉的衔接带在同一世界坐标中重绘，南侧庭院保留；对周围五处缺细节边界单独做岩土纹理延展，保护模型覆盖、道路材质、海洋和原庭院。没有加入安其拉副本图页。
- 全域平坦／低频渐变检测、周围地表色彩过渡和真实材质纹理共同处理低清方块；缺少原始细节的位置使用装饰性填充，不据此新增道路、建筑或任务点，也不把推导纹理称为实测地形。

所有精细绘制都在制作阶段完成。游戏内仍只读取贴片，不运行模型渲染器。

## 保留的功能

- 地形模式海洋保持统一的深海样式；原版完整世界总览和手绘背景可选。
- 名称仅近景显示鼠标当前区域，最多一个；远景隐藏。字体先用内置对象初始化，用户字体失败仍有后备。
- 任务、旅店、飞行点只读取鼠标区域节点，远景跳过节点表；玩家、个人标记保留。地形区域使用 ADT AreaID 与父区，手绘沿用绘画轮廓。
- 总览按比例铺满并固定；放大围绕鼠标、左键拖动、右键缩小，视野受世界边界约束。缩放立即更新美术和已有图标，节点分别合并刷新。
- M 打开当前位置优先；未知区域不信任残留页坐标，有限重试且用户操作取消。后台选图不移动相机，明确任务跳转保留，会话位置随区域变化失效。
- 分类、阵营、Atlas 点击、pfQuest 提示及原点击回调、旧设置迁移和原地图回退继续保留。平移缩放不重建任务数据库或重置追踪器。

## 使用与升级

完整退出并重启客户端，启用“乌龟服无缝世界地图”，加载新文件。无需删除保存设置；若城市细节之前关闭，可在“地图样式”中开启。

- M 或 /tsm：开关地图，当前位置优先。
- /tsm world：完整世界；列表支持中文和文件名搜索。
- “原地图”或 /tsm native：原地图回退。
- 标题栏可移动窗口；Esc 关闭；Ctrl+左键添加个人标记，右键删除该标记。

## 资源、制作与检查

当前共 7,318 张 BLP、480,675,512 字节，约 458.4 MiB。新增／替换 6,024 张 v7 地形和城市，保留全部 v4 手绘、v5 原版总览及 v6 海面；旧 v6 地形和城市资源删除，历史报告与 Git 记录保留。完整指纹和制作依据见 PluginHistory/Research/TurtleSeamlessMap-0.6.0地形资源-20261024.json。磁盘体积不是运行时内存或显存测量。

贴片仍为 256×256 BLP2/DXT3，内部 254×254 有效、周围一像素取相邻内容。背景、各大陆和各城市独立复用最多 256 个纹理槽位，移出视口清除引用；纹理失败可整层退低一级。玩家、任务、个人标记的原投影不变。

玩家使用预制贴图即可，无需 Python、PowerShell 或原始模型。维护者可用 Tools/build_turtle_map_hd.py 在独立 v7 候选制作、审查后 --deploy-reviewed 部署；--audit-candidate 检查文件及庭院保护，--probe 可制作局部预览。离线工具在 Windows 使用 Python／Pillow／NumPy／Lupa 和 PowerShell 的内存内编译，不安装游戏 DLL。旧制作器保留历史用途，不要部署覆盖现用版本。

61 组 Lua 5.1／严格 1.12 模拟、资源、真实静态绘制器检查通过，包含高精度拼接抽查、实际模型放置矩形、M2 旧版头部、WMO 尾部、材质透明度、遮挡／裁剪、庭院像素保护、全文件指纹与解码、定位和任务兼容、字体失败后备、近景名称、单区节点及槽位上限。已查看七城候选、希利苏斯与两大陆，并制作三个同位置／同倍率的 Lua 绘制对比；这些是离线合成，非游戏实测。

## 真实限制

缺源位置的岩土填充是装饰性延展；模型仅静态几何与基础材质，没有重现完整动画、粒子、透明效果、WMO 内部附属物及客户端全部光照。树冠不额外盖住城市道路。一个船模型未被读取器接受、一个砖堆文件缺失，以及部分占位材质缺失的位置沿用原生背景，报告分别列明。地下主城仍为原生房间的平面合成，没有楼层选择器。

所有街区、入口、海岸、推导填充、快速缩放及帧率／显存仍待游戏验收。S_WorldMap 会话旗标、任意第三方图层、任务路线、全部团队标记及 pfQuest 所有视觉设置未完整移植，可用原地图回退。

本机原始提取的 173 图页、3,551 张 BLP 及 PNG 未修改；游戏档案、其他插件、DLL、WTF 未改。本版仅查阅格式资料，未下载第三方地图或套用正式服地形。代码许可见随附文件，美术保留原权利归属；代码许可不代表全部游戏资源的再分发许可。
