# Turtle Seamless Map 0.2.0

独立的乌龟服 1.12 世界地图插件。启用后接管 `M` 键及常见默认地图打开入口；不依赖 ModernMapMarkers 或 pfQuest 才能运行。

## 当前功能

- 世界、卡利姆多、东部王国、室外区域和主城共用一个连续画布，保留两大陆的海洋间隔；不再使用首版两套固定偏移。滚轮围绕鼠标缩放，左键拖动，右键缩小。
- 运行时包含世界、2 个大陆、53 个室外区域和 7 座主城，共 63 项地图数据。“区域列表”只列 60 个室外/城市图页，支持中文、文件名查找及滚轮翻页。
- 副本内部、楼层、入口放大图、洞穴/通道、GM 岛及无坐标备用图页不进入运行时浏览。野外副本入口图标、Atlas 跳转保留。“区域定位”在同一世界画布中定位当前区域。
- 区域绘图与标记共用详情门槛：远景不显示任务、飞行点、旅店等区域节点，并在读取区域节点表之前跳过。玩家、个人标记仍可显示。其他标记提供方须遵守下方接口规则。
- 暴风城、奥格瑞玛、铁炉堡、雷霆崖、达纳苏斯、幽暗城和阿拉萨拉斯只在进一步放大、视野中心或鼠标缩放焦点靠近城市时显示详细层及城市节点；退出门槛留有缓冲，普通区域视图保留父区域原有城市示意。
- 世界总图在远景显示；近景过渡为干净海面、客户端大陆陆地补底及区域贴图。区域之间的原未绘制部分采用本客户端大陆颜色/图形填充，不移植正式服地形。
- “我的位置”定位玩家；`Ctrl+左键` 添加个人标记，标记上右键删除；保存浏览位置和缩放。
- “标记筛选”复用已加载 ModernMapMarkers 的副本、团本、世界首领和交通分类、阵营筛选，点击副本继续打开 Atlas。
- 读取已加载 pfQuest 的任务/资源节点，复用任务提示与点击回调；“任务开关”控制本图显示。地图平移和缩放不调用任务节点重建、追踪器重置或全局切换区域。

## 使用

完全退出并重新启动客户端后，在角色插件列表启用“乌龟服无缝世界地图”。本次新增目录后，仅重载界面不保证客户端能发现新插件。

- `M` 或 `/tsm`：开关地图。
- `/tsm world`：打开连续世界视图。
- “原地图”或 `/tsm native`：临时打开原有地图，供兼容性对照和使用尚未适配的功能。
- 拖动窗口标题移动整个窗口；地图内部拖动移动视野；`Esc` 关闭。

原有 ModernMapMarkers、S_WorldMap、pfUI、pfQuest 文件没有改动。原图窗口保留供回退，不要求删除其他插件。

## 数据完整性与限制

从当前安装的 MPQ 按补丁顺序解析 DBC、底图和探索覆盖层。3,551 个地图 BLP 文件全部提取、解码并保存 SHA-256，173 个图页均完成底图/覆盖层检查；本次清单缺失项为零。

完整原始资源及 1002×668 无损预览保存在本地 `PluginHistory/staging/turtle-seamless-map/`，不加入 Git。插件只携带 792 个派生绘图贴片，约 49.6 MiB；副本图页不再载入运行时数据。派生贴片采用当前客户端本来就在使用的 BLP2/DXT3 格式，颜色经过块压缩，透明度为 4 位；不把派生贴片称为无损原图。

连续浏览功能与美术接缝优化分开验收。当前使用原探索覆盖层、海陆补底和边缘渐变连接地图。未绘制山地有大陆补底，但不等同于新增高精度山脉美术；部分区域色差、海岸过渡及新增区域位置仍需游戏内逐区确认；不声称达到 OpenMap 的全部美术效果。区域命中先使用矩形边界，城市只在详细层启用后参与命中，交叠处优先较小地图，不作为精确地形归属判断。

目前明确适配 ModernMapMarkers、Atlas 跳转及 pfQuest 节点。S_WorldMap 的旧会话手动旗标、其他插件任意图层、任务路线连线、所有团队地图标记及 pfQuest 动画/全部视觉设置尚未完整移植；相关功能仍可通过“原地图”使用。标记密集超过当前帧预算时显示提示，需要放大查看。

升级时自动迁移首版个人标记和视图；原记录保存在 `TurtleSeamlessMapDB.layoutV1Backup`。移除图页或无法确定位置的旧标记保存在 `unplacedNotes` 并提示，不静默丢失或猜测位置。无需手工删除保存设置。

本版优先功能完整性，未完成集中性能优化，也没有实测帧率结论。

自动检查使用 Lua 5.1 模拟 1.12 所需接口，并严格检查 FontString 字体初始化与字体路径失败。实际游戏加载、贴图显示、交互、帧率和内存仍待游戏验收。

## 其他插件接入

`TurtleSeamlessMap:RegisterProvider(name, function(map) ... end)` 注册绘图回调。

`MapToWorld(worldMapAreaID, x, y)` 将区域内 0..1 坐标转成统一世界坐标，不支持的图页返回空值。

`CanShowMapPins(map.byID[worldMapAreaID])` 检查当前区域详情是否可见。提供方必须先检查，再遍历该区域节点；不要在远景扫描全大陆任务、旅店或飞行点。

`AddPin(key, x, y, texturePath, size, onEnter, onLeave, onClick, data)` 绘制可见标记；回调接收标记 frame，点击另接收按钮名。提供方应读取自身缓存，不在绘图回调中切换客户端地图或重建任务状态。
