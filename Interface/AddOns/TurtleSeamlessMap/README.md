# Turtle Seamless Map 0.4.0

独立的乌龟服 1.12 世界地图插件。接管 M 及常见原地图入口；不依赖 ModernMapMarkers 或 pfQuest 才能运行。世界、两大陆、53 个室外区域及七城共用同一坐标画布；副本内部图页不进入浏览。

0.4.0 默认使用“真实地形详情＋原版世界总览”。点击工具栏“地图样式”，可分别切换“真实地形／手绘”“原版世界／连续地图”，以及近景城市图开关；选择会保存。小窗口工具栏自动分两行，地图仍保持原比例。

## 当前功能

- 真实地形采用本机小地图俯视贴片按固定地理网格生成五级图集，每格只有一个地形来源，不按区域插画大小覆盖；贫瘠之地、费伍德及相邻区连续显示。手绘模式保留 0.3.0 图集，可随时切回。
- 地图与节点分开控制：任务、旅店、飞行点等仍只读取鼠标区域的节点；远景先跳过区域节点表。移出画布或操作列表时保留焦点；玩家与个人标记保留。
- 真实地形的区域判定读取离线提取的 ADT AreaID，并解析父区；手绘模式继续使用绘画轮廓。提尔之手手绘图保留专用轮廓，不退回整页方框。
- 七城保留近景门槛，沿街区和码头轮廓显示，去掉图框、指南针和标题饰带；外围直接衔接连续大陆，不再覆盖模糊父区。地下城市仍使用独立近景层。
- 原版总览显示未改动的完整 World 原画；连续总览使用所选详情样式组成两大陆。开始放大进入详情，M 打开仍优先当前位置。近景保留原风格海洋背景；地形只移除与外海连通的深水，保留内陆湖泊和森林暗部。
- 总览按原比例铺满并固定；放大后围绕鼠标缩放、左键拖动、右键缩小，视野受世界边界约束。
- M/普通原入口统一核对当前位置；真实区名为空或未识别时不信任残留页，也不读取该页坐标。最多八次短间隔同步，用户缩放、拖动、工具栏操作或关闭即取消。后台 SetMapZoom 查询不移动相机，明确任务/标记跳转保留；临时忽略状态在错误时也恢复。位置缓存仅在会话内使用，区域变化即失效；区域别名来自本机 DBC。
- 保留 ModernMapMarkers 分类、阵营及 Atlas 点击，pfQuest 原任务提示和点击回调。平移/缩放不重建节点、不重置追踪器、不持续切换客户端选中地图。

## 使用与升级

完整退出并重启客户端，启用“乌龟服无缝世界地图”，以重新载入新贴图。无需删除保存设置。

- M 或 /tsm：开关地图，打开时当前位置优先。
- /tsm world：完整世界；区域列表支持中文和文件名搜索。
- “原地图”或 /tsm native：使用原地图，供兼容对照和未适配功能。
- 标题栏可移动窗口；Esc 关闭；Ctrl+左键添加个人标记，标记右键删除。

保留首版数据迁移、原记录备份及无法定位标记的隔离保存，不静默丢弃。其他插件、MPQ、WTF 未修改。

## 资源与实现

本机原始提取证据仍在忽略的暂存目录：173 图页、3,551 张 BLP 和完整 PNG 均保持不变。保留 1,270 张手绘美术，新增 1,096 张地形/原版总览，共 2,366 张、155,408,344 字节（约 148.2 MiB）。具体文件和指纹见仓库 PluginHistory/Research/TurtleSeamlessMap-0.3.0资源-20261024.json 与 TurtleSeamlessMap-0.4.0地形资源-20261024.json；磁盘体积不等于实测内存/显存，运行时只绘制当前样式和视口。

每张贴片为客户端已有使用证据的 BLP2/DXT3，256×256 内部 254×254 为有效区域，四周一像素取相邻图集内容，降低接缝。各级共享投影；原区域矩形和玩家/任务/个人标记坐标不变，七城保留原像素密度。

背景及每块大陆各复用最多 256 个纹理槽位，移出视口清除纹理引用；只访问视口网格，不逐帧扫描全图贴片。鼠标单独移区时复用未变化的大陆与背景，纹理失败可退到该大陆较低一级完整图集。驱动缓存不受 Lua 控制，槽位数和磁盘体积不等于实测内存/显存。

缩放立即更新美术和已有图标，节点分别合并刷新。未使用现代地图 API、运行时遮罩、网格变形或渲染目标。

## 完整性与限制

53 个室外区域和七城的地理记录不变。有效展示范围解析 1,794 个 ADT 格：1,703 格使用原预渲染小地图，89 个缺索引格确认完全在水面以下，另两格用真实地形材质/高度/水面补图。这两格没有渲染建筑/树木模型，记录中明确标注；展示范围外的开发/无用格未盲目加入。区域标签由实际地理归属统计定位，铁炉堡、幽暗城等地下区域仍用城市图。

手绘模式的无图山地缝隙使用原图纸纹与山线作装饰填充，报告区分这部分；没有添加道路、城镇或任务点。手绘原美术的色差和边界比例仍可能可见，该模式不是从零逐像素重绘的整大陆新图。原世界背景像素有限，深度放大仍会变软。

45 组 Lua 5.1/严格 1.12 模拟与资源检查通过，覆盖新增定位路径、真实区域归属、样式保存、小窗口布局、字体失败后备和既有兼容。旧回归在保留的手绘/连续模式执行，新检查另测实际默认模式。实际首次开图、所有海岸/文字、地下城市、快速缩放、帧率和显存仍须游戏验收。客户端原贴片有些光照/色差或地形粗边会保留；资源完整不代表全部边缘已游戏验收。

目前明确适配 ModernMapMarkers、Atlas 和 pfQuest。S_WorldMap 会话旗标、其他插件任意图层、任务路线、所有团队标记及 pfQuest 全部视觉设置尚未完整移植，可用“原地图”回退。

## 其他插件接入

- TurtleSeamlessMap:RegisterProvider(name, callback)：注册提供方。
- MapToWorld(worldMapAreaID,x,y)：区域 0..1 坐标转世界坐标，不支持图页返回空值。
- CanShowMapPins(map.byID[id])：判断焦点详情；必须先判断再遍历节点，不扫描整大陆。
- AddPin(key,x,y,texture,size,onEnter,onLeave,onClick,data,mapID)：绘制可见标记。可选 mapID 使移区/缩放即时隐藏旧节点；回调收到图标 frame，点击另收按钮名。不得在绘图回调切图或重建任务状态。

## 制作与来源

Tools/build_turtle_map_atlas.py --audit 在独立暂存目录生成候选并核查本机小地图；人工审查整图、代表片区与城市后，--deploy-reviewed 只部署指纹校验通过的候选。旧 v2/v3 生成器仅作历史复现，不要覆盖现用资源。

真实地形使用 Tools/build_turtle_map_terrain.py 先生成独立候选，审查后用 --deploy-reviewed 部署；保留手绘资源，不覆盖其历史报告。只读读取器按需启用 terrain.MPQ，未改动游戏档案或部署 DLL。

参考用户提供的 OpenMap 中地理分层、绘画覆盖、边缘调色和背景分离思路；未直接套用正式服地理/接口，本版未下载第三方地图。代码许可见随附文件，美术保留原权利归属；代码许可不代表全部游戏资源的再分发许可。
