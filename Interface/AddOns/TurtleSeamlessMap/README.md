# Turtle Seamless Map 0.7.0

独立的乌龟服 1.12 世界地图插件。接管 M 和常见鼠标开图入口，可独立运行，适配 ModernMapMarkers、Atlas、pfQuest。世界、两大陆、53 个室外区域和七城共用原坐标画布；副本图页不进入浏览。

默认真实地形详情＋原版世界总览。“地图样式”可切换真实地形／手绘、原版世界／连续地图，并保存。地形模式“城市细节”控制额外高清近景；五座地表城市同时融入大陆基础图集，地下两城保留近景专层。手绘模式保留城市插画。小窗口工具栏两行，地图保持原比例。

## 0.7.0 修复与画面变化

- 阻止初始化、后台查询和按钮更新过程自动弹图；后台保护标记不再被当成明确导航。M 和正常鼠标开图重新请求当前位置，空的真实区域名不接受缓存页／子区名，有限重试仍可被用户操作取消。明确的任务／地图标记跳转保留其目标。
- 修正 JSON 中间清单把贴片数字编号变成文字的问题，恢复东部王国全部缩放层；写出 Lua 后重新核对每个数字编号与实际文件。
- 真实地形不再因鼠标进入或离开城市而切换画面。地表城市的同一图像进入大陆各缩放层，高清专层按视野和倍率稳定叠加；仅移动鼠标时复用全部地形贴片，更新区域名称。
- 两大陆的缺细节边界改用共享世界纹理坐标、连续色彩场和跨块柔化；道路按实际材质透明权重保护，避免一条小路连同整块地形都保留为方块。补细节使用每 ADT 768 像素的实际材质／高度数据，图集最高密度仍为 32。
- 对安戈洛南侧、希利苏斯西侧、厄运之槌周边、菲拉斯—千针石林、灰谷—海加尔、冬泉谷—月光林地另做地貌延展。地形纹理通过重叠匹配与最小误差接缝合成，减轻镜像、拉伸和重复小方块；缺源位置属于装饰性处理，不代表新测绘的山脉、道路或可通行区域。
- 厄运之槌只重绘实际放置在卡利姆多上的外部建筑，按模型覆盖混入地形，不加入副本图页。原安其拉衔接带和南侧庭院像素继续保护。
- 补上暴风城建筑模型中的 22 组水面网格，运河按真实高度覆盖水底，桥梁仍在水上。静态水色与波纹是地图表现，没有模拟完整客户端水面着色。
- 地形模式的任务、旅店、飞行点按放大程度与视口读取可见区域，取消鼠标单区限制；远景跳过节点表，画面外节点先裁剪再读详情，保留 900 图钉上限。手绘的旧节点选择逻辑保留。

所有模型绘制和纹理合成都在制作阶段完成。游戏内只读取贴片，不运行这些制作工具。

## 使用与升级

完整退出并重启客户端加载新贴图，无需删除保存设置。若城市细节之前关闭，可在“地图样式”中开启。

- M 或 /tsm：开关地图，当前位置优先。
- /tsm world：完整世界；区域列表支持中文和文件名搜索。
- “原地图”或 /tsm native：原地图回退。
- 标题栏可移动窗口；Esc 关闭；Ctrl+左键添加个人标记，右键删除该标记。
- 放大围绕鼠标，左键拖动、右键缩小。完整总览按比例铺满并固定。

名称只在区域近景显示，最多一个；远景隐藏。字体先以内置对象初始化，用户字体失败有后备。玩家、个人标记、分类／阵营筛选、Atlas 点击、pfQuest 提示与原点击回调、设置迁移均保留。平移缩放不重建任务数据库或重置追踪器。

## 资源、制作与检查

本版共 7,318 张、480,675,512 字节（约 458.4 MiB），替换大陆和暴风城图集，保留其他城市、v4 手绘、v5 原版总览与 v6 海面。贴片仍为 256×256 BLP2/DXT3，内部 254×254，周围一像素取相邻内容。每个场景最多复用 256 个纹理槽，移出视口清除引用，贴图失败可整层退低一级。磁盘体积不是运行时内存或显存测量。

维护者使用 Tools/build_turtle_map_continuity.py：world 制作两大陆候选，city 修复暴风城，finish 处理指定边界与厄运外景，pack 打包，audit 检查数字索引、海岸 alpha 和受保护像素，审查后 deploy 部署。all 完成制作与审计，不自动部署。候选和原模型在忽略的 staging 目录，旧制作器和历史报告保留，不应直接覆盖现用版本。玩家无需 Python、PowerShell 或原模型，也不安装额外游戏 DLL。

69 组完整检查通过，覆盖登录及定位、后台查询、两大陆各层实际绘制、主城不随鼠标切换、视口节点、字体失败后备、模型液面／桥梁深度、真实资源／指纹、拼接边缘、地貌合成的可重复性与原坐标保护。离线模拟和预览不等同于游戏实测。完整依据见 PluginHistory/Research/TurtleSeamlessMap-0.7.0实现-20261024.md 及同版本地形资源报告。

## 真实限制

缺源位置为参考周围岩土风格的装饰延展，不能据此判断路线或可通行地形。普通室外小建筑仍受原始预渲染素材精度限制；没有把全世界都换成重新建模的高清场景。模型动画、粒子、全部透明效果、WMO 内部附属物和完整光照未重现；原有船模型／砖堆和占位材质后备继续保留。地下主城仍为原生房间的平面合成，没有楼层选择器。

登录入口、街区／桥梁、接缝、快速缩放、帧率和显存仍需游戏验收。任意第三方图层、任务路线、全部团队标记及 pfQuest 的全部视觉设置未完整移植，可用原地图回退。直接从后台调用原窗口 Show 不再弹出地图；自定义开图脚本应调用 ToggleWorldMap 或 /tsm，明确任务／标记接口继续适配。

本机原提取 173 图页、3,551 张 BLP 及 PNG 未修改；其他插件、游戏档案、DLL、WTF 未改。水面格式查阅 [pywowlib 的 WMO 网格读取](https://github.com/wowdev/pywowlib/blob/master/file_formats/wmo_format_group.py)，并以本机数据核对；未下载或套用其他服务器地形。代码许可见随附文件，美术保留原权利归属；代码许可不代表全部游戏资源的再分发许可。
