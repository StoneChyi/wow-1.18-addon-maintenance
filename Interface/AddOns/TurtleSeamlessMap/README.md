# Turtle Seamless Map 0.5.0

独立的乌龟服 1.12 世界地图插件。接管 M 及常见原地图入口；可独立运行，提供 ModernMapMarkers、Atlas 和 pfQuest 的明确适配。世界、两大陆、53 个室外区域及七城共用原坐标画布；副本内部图页不进入浏览。

默认“真实地形详情＋原版世界总览”。“地图样式”可切换真实地形／手绘、原版世界／连续地图，并保存。地形模式第三项为“室内图”，控制铁炉堡、幽暗城近景；手绘模式仍控制原城市插画。小窗口工具栏两行，地图保持原比例。

## 当前功能

- 地形按真实地理网格离线生成五级图集，视口直接取图；地表五城沿用大陆原生实景，不再自动叠加手绘城市图。铁炉堡、幽暗城近景改用原生室内小地图，依据 WMO 放置位置和旋转对齐；透明外围按房间形状保留，封闭岩壁空隙用暗色底衬，不显示方形底板。手绘模式仍保留七城原图。
- 地形模式全程使用相同的深海水面底色，保留原生海岸、浅水和内陆湖泊；不露出羊皮纸。选择原版世界总览时，最远一级仍显示完整原画；手绘详情保留原背景样式。
- 全域检查 1,794 块 ADT、459,264 个小地形格及 3,427 条相邻拼接边。335 块原生贴图中识别到的纯色缺细节区域，经实际地形材质、坡度和周围颜色过渡补图，修复范围涉及 15,716 个小格（包含局部边缘）。补图是装饰性地形过渡，不能视作恢复不存在的真实场景；不会据此新增道路、建筑或任务点。
- 名称只在近景显示鼠标当前区域，覆盖比例至少 0.72，最多一个；世界和大陆远景不散落显示部分区域名称。字体首次写字前用内置字体对象初始化，用户字体不可用仍有后备。
- 任务、旅店、飞行点等仍只读取鼠标区域节点；远景跳过区域节点表。玩家与个人标记保留。地形区域读取 ADT AreaID 及父区，手绘沿用绘画轮廓。
- 总览按原比例铺满并固定；放大围绕鼠标、左键拖动、右键缩小，视野受世界边界约束。缩放立即更新美术和已有图标，节点分别合并刷新。
- M 打开当前位置优先；当前区名未知时不读残留页坐标，有限重试且用户操作取消。后台地图查询不移动相机，明确任务跳转保留。位置缓存随区域变化失效。
- 保留分类、阵营及 Atlas 点击，pfQuest 提示和原点击回调；平移、缩放不重建任务数据库，不重置追踪器。原地图回退、旧设置迁移和隔离保存继续保留。

## 使用与升级

完整退出并重启客户端，启用“乌龟服无缝世界地图”，重新载入新贴图。无需删除保存设置。

- M 或 /tsm：开关地图，当前位置优先。
- /tsm world：完整世界；列表支持中文和文件名搜索。
- “原地图”或 /tsm native：原地图回退。
- 标题栏可移动窗口；Esc 关闭；Ctrl+左键添加个人标记，右键删除该标记。

## 资源与制作

本机原始提取的 173 图页、3,551 张 BLP 及 PNG 均在忽略的暂存目录保留。当前美术共 2,853 张、187,396,452 字节（约 178.7 MiB）：保留全部 v4 手绘和 12 张 v5 原版总览，以 1,571 张 v6 地形／城市／海面替换旧 v5 地形。历史报告保留，当前完整指纹见 PluginHistory/Research/TurtleSeamlessMap-0.5.0地形资源-20261024.json。

每张为 256×256 BLP2/DXT3，内部 254×254 有效，周围一像素取相邻图集内容。各级共享投影；MapData、玩家／任务／个人标记坐标和区域归属数据不变。背景、每大陆、每个室内城市各最多 256 个复用槽位，移出视口清除引用；鼠标换区复用不变的大陆与背景。显存和帧率未实测，磁盘体积不是运行时占用。

Tools/refine_turtle_map_terrain.py 是当前生成器：先在独立 v6 候选制作及检查，审查后 --deploy-reviewed 部署；--audit-candidate 重查拼接边，--refresh-cities 可只重建城市。Tools/build_turtle_map_terrain.py 保留 0.4.0 历史制作流程，不要用其部署覆盖现版本。读取器按需只读 terrain.MPQ／wmo.MPQ，未修改游戏档案、其他插件、DLL 或 WTF。本版未下载第三方地图。

## 验证与限制

51 组 Lua 5.1／严格 1.12 模拟、数据与资源检查通过，包括原定位与兼容回归、全资源指纹和解码、城市实景及槽位释放、WMO 放置矩形校验、室内空隙不变方框、统一水面、近景单标签、字体失败后备、单区节点及原图保存。已查看两大陆、安戈洛、贫瘠之地、费伍德、艾萨拉及三城的 Lua 绘制状态合成预览；这不是游戏截图或游戏验收。

没有原始细节的区域采用材质／高度与周边颜色推导的过渡，仍可能保留粗边、色差和未建模地形。两个原本缺少小地图的陆地格仍只含材质／高度／水面，没有建筑、树木模型。室内使用原生预渲染组，重叠处较低组优先，不是实时三维场景和完整楼层选择器；所有城市任务标记、入口、边界、快速缩放、帧率和显存仍待实际游戏验收。

S_WorldMap 会话旗标、任意第三方图层、任务路线、全部团队标记和 pfQuest 所有视觉设置未完整移植，可用原地图回退。

## 其他插件接入

- RegisterProvider(name, callback)：注册提供方。
- MapToWorld(mapID,x,y)：区域 0..1 坐标转原世界坐标，不支持图页返回空值。
- CanShowMapPins(map)：必须先判断再遍历节点，避免扫描整大陆。
- AddPin(key,x,y,texture,size,onEnter,onLeave,onClick,data,mapID)：绘制可见标记。可选 mapID 让移区或缩放即时隐藏旧节点；回调收到图标 frame，点击另收按钮名。不得在绘图回调切图或重建任务状态。

参考用户提供的 OpenMap 的分层、覆盖及背景分离思路，未套用正式服地图接口。代码许可见随附文件，美术保留原权利归属；代码许可不代表全部游戏资源的再分发许可。
