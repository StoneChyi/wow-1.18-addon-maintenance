# Turtle Seamless Map 0.8.0

独立的乌龟服 1.12 世界地图插件。接管 M 和常见鼠标开图入口，可独立运行，适配 ModernMapMarkers、Atlas、pfQuest。世界、两大陆、53 个室外区域和七城共用原坐标画布；副本图页不进入浏览。

默认真实地形详情＋原版世界总览。“地图样式”可切换真实地形／手绘、原版世界／连续地图，并保存。地表城市融入大陆，城市细节控制额外近景；地下两城在近景使用独立室内切面。名称只在区域近景显示，最多一个。

## 0.8.0 地貌与城市修复

- 从原始地形素材重新生成大陆修复层，取消沿用旧补绘结果及整块城市／安其拉矩形保护。实际道路权重、水面网格和建筑轮廓分别处理，原坐标与标记投影保留。
- 将两侧地表材质的实际贡献权重放在同一连续画布上混合。岩石、森林、沙地和雪地的细节一起过渡，避免仅柔化底色后仍留下笔直的材质边框；不再将同一岩石小样重复用于各类区域。
- 颜色有效与细节有效分开判断，保留沙地、雪地等原有生境颜色。已检查的缺源平坦边缘参考周围实际材质及边界高度作装饰性延展，不新增道路、山口、建筑或任务点。
- 安其拉大门／南侧庭院、厄运之槌外部和五座地表主城按实际模型覆盖混入大陆；高清近景使用相同背景及相同模型位置，移入移出鼠标不会换图。城市外围不再带入整张旧背景。
- 铁炉堡、幽暗城补闭合岩壁轮廓，并在室内层启用时保持不透明，减少雪地、草地与地表水系透进房间的现象。原房间和入口图像保留，没有添加楼层选择器。
- 海岸按实际启用的水面格子和高度处理，连接外海的水面采用统一浅水／深水过渡；内陆水面与暴风城运河保留。暴风城仍使用真实液面网格，桥梁在水上。
- 新地形图集改用压缩块对齐的四像素边缘，内部 248×248，贴片仍为 256×256 BLP2/DXT3。相邻共享边缘在压缩后也应完全一致；旧手绘／原版图集仍使用各自原布局。

所有场景合成和材质处理都在制作阶段完成。游戏内只加载视口中的贴片，不执行这些制作计算；每个场景最多复用 256 个纹理槽，画外清除引用，资源失败可整层降一级。

## 使用与升级

完整退出并重启客户端载入新贴图，无需删除保存设置。若城市细节之前关闭，可在“地图样式”中开启。

- M 或 /tsm：开关地图，当前位置优先。
- /tsm world：完整世界；原版总览与连续地图可切换。
- “原地图”或 /tsm native：原地图回退。
- 标题栏移动窗口，Esc 关闭，左键拖动，滚轮围绕鼠标缩放，右键缩小。
- Ctrl+左键添加个人标记，右键删除该标记；区域列表支持中文和文件名搜索。

保留 0.7.0 的登录／后台误开图保护、真实位置优先和有限重试、东部王国数字索引、主城稳定显示、多区域视口节点、900 图钉上限及远景裁剪。任务提示与点击回调、筛选、Atlas 入口、设置迁移及字体失败后备继续保留。手绘模式的旧节点选择逻辑保留。

## 资源与验证

本版共 7,478 张贴片、491,184,952 字节（约 468.4 MiB），其中 6,184 张为本版地形／城市资源。保留旧手绘、原版总览和海面图集；运行时仍按视口加载，磁盘体积不等于显存占用。

81 组离线检查通过（64.643 秒），包括严格 1.12 字体／接口模拟、两大陆各层实际绘制、旧登录／定位／节点回归、材质跨块采样、实际液面／桥梁深度、原生房间与模型保护。11,708 对相邻贴图压缩后的共享 RGBA 最大差为 0；全量资源指纹与数字引用一致。已复查 51 处记录、60 个区域／城市预览和 98 个完整地理窗口。以上不是游戏实测。

制作流程见 Tools/rebuild_turtle_map_landscape.py：两大陆分别 prepare（包含分类）、materials、world，再 compose、pack、audit。Tools/review_turtle_map_landscape.py 生成区域、完整地理窗口和逐项对照页；人工审查通过后 deploy 才替换插件。候选、原模型与原始提取位于忽略的 staging，不上传游戏档案、账号设置或个人截图。历史制作器用于历史依据，不应直接覆盖现用插件。

## 真实限制

缺源边缘的材质／高度延展属于画面表现，不能据此判断可通行地形。原始普通室外物件仍有分辨率上限；本版没有声称恢复不存在的原始细节，也未将全世界重建为新的高精度三维模型。有效地形的陡崖、真实道路、建筑直线和水岸不能仅因笔直而被判作错误。仍需地理／游戏确认的候选在逐项记录中保留。

地下城市仍是原生房间的平面合成。模型动画、粒子、全部透明效果、WMO 内部附属物和完整客户端光照未重现，既有缺失模型后备保留。全部接缝、街区／桥梁、登录／传送、快速缩放、帧率和显存需要游戏验收；离线模拟、静态预览与磁盘体积不能代替实际游戏测量。

代码许可见随附文件，美术保留原权利归属。玩家无需 Python、PowerShell、原模型或额外游戏 DLL。
