# 2026-08-21 工作日志

## libdebuff 计时修复（智慧审判无计时 / 毒蛇钉刺计时偏短）

文件：`libs/libdebuff.lua`

### 根因
1. **智慧审判等审判类 debuff 不显示计时**：审判的「施放名」是 `审判`，但目标身上的 debuff 名是 `智慧审判`（zhCN）。`DEBUFF_ADDED_OTHER` 里用 `pendingCasts[guid][spellName]` / `allAuraCasts[guid][spellName]` 反查施法者时，键名是 `审判` 而对不上 `智慧审判`，导致 `casterGuid` 解析失败 → `isOurs=false` → `ownDebuffs["智慧审判"]` 不建立 → 无倒计时。
2. **毒蛇钉刺（及类似）proc/陷阱重新施加时计时偏短**：当 `AURA_CAST` 的 `durationMs=0` 回退到基础库 `L["debuffs"]["毒蛇钉刺"][0]=15` 时，忽略玩家真实（含强化毒蛇钉刺天赋）的持续时间。

### 改动
- 新增模块级缓存 `pfUI.libdebuff_actual_duration`（local `actualDuration`）：在 `AURA_CAST` 玩家自身施放且 `duration>0` 时，缓存该法术真实持续时间（来自服务端，已含天赋/等级）。
- `AURA_CAST` 的 `duration==0` 回退分支：优先用 `actualDuration[spellName]`，再回退 DB。
- `DEBUFF_ADDED_OTHER` 的无 `AURA_CAST` 数据回退：同样优先 `actualDuration[spellName]`。
- `DEBUFF_ADDED_OTHER` 新增「审判类 debuff 特殊处理」：当 `spellName` 在 `L["judgements"]` 中且未解析到施法者时，从 `allAuraCasts[guid]["审判"]`（`pendingCasts[guid]["审判"]` 兜底）解析 `casterGuid`，并把施放名计时镜像到真实 debuff 名（duration 取 `max(原值, GetDuration)`），使 `ownDebuffs` 得以建立并显示 10s 计时。

### 验证
- `luaparse` 语法校验通过（SYNTAX OK）。
- 需在客户端实测：骑士对目标放智慧审判应显示 10s 倒计时；猎人施毒蛇钉刺（点强化毒蛇钉刺）后由猫鼬撕咬/爆炸陷阱刷新，计时应保持真实值而非固定 15s。
- 注意：若毒蛇钉刺从未被直接施放、只由 proc 首次施加，则缓存为空，回退仍是基础 15s（无天赋时正确；有点天赋时偏短）。常规玩法先施放再刷新，缓存已填充，无此问题。
