# 2026-08-16 工作日志

## 性能优化：单位框架 glow 动画移除常驻 OnUpdate
- 文件: `api/unitframes.lua`。
- 现状：pfUI 已大量优化（libthrottle 分级节流、姓名板中央 OnUpdate+自适应节流、单位框架心跳轮询+事件驱动、buff 合并单一 OnUpdate 等）。
- 发现并修复的剩余浪费：发光动画（glow）有两个「每帧无条件运行」的 OnUpdate：
  1. `pfUI.uf.glow` 共享帧的 OnUpdate 每帧调用 `GetFramerate()`（即使没有任何 glow 显示）。
  2. 每个单位框架的 `f.glow` 都挂了 `UpdateGlowAnimation`，隐藏时仍每帧执行 `SetAlpha`（约 45-50 个框架 × 每帧）。
- 修复：删除共享帧的常驻 OnUpdate（它驱动 `val` 脉冲，但 `mod=0`+`val=0.6` 实际卡死在 0.6 不跳动，属于死代码）；`UpdateGlowAnimation` 开头加 `if not this:IsShown() then return end` 守卫。视觉行为不变（glow 仍以 0.6 alpha 显示）。
- 校验：luaparse Lua 5.1 语法通过。
- 结论：若想恢复 glow 的呼吸脉冲效果（代码本意），可改为基于 GetTime 的时间驱动，待用户确认。

## glow 改为真正呼吸效果（时间驱动）
- 用户确认要做呼吸脉冲。已将 `UpdateGlowAnimation` 改为基于 `GetTime()` 的时间驱动：
  - `val` 在 0.4↔0.8 之间往返，速率 0.3 alpha/秒（半周期约 1.3s，完整约 2.67s），与旧代码 30fps 参考速率一致。
  - `dt` 用 `g.lastUpdate` 差量计算，并 clamp 到 0.05s 上限，避免长时间隐藏后重新显示时跳变。
  - 仍保留 `if not this:IsShown() then return end` 守卫（隐藏不消耗），无常驻 OnUpdate、无每帧 GetFramerate。
- 校验：luaparse Lua 5.1 语法通过。
- 修改文件: `api/config.lua`, `modules/gui.lua`, `api/unitframes.lua`, `env/translations_zhCN.lua`
- 新增配置项 `hide_fullhp`，默认值 "0"（关闭）
- GUI 中在 Auto Hide 区域添加 "Only Hide at Full Health" / "满血才隐藏" 复选框
- OnUpdate 逻辑: 当 hide_fullhp 开启时，只有单位满血(hp >= hpmax)才允许自动隐藏；掉血时保持显示
- 逻辑优先级: 鼠标悬停/战斗中显示 > 满血才隐藏判断 > 普通自动隐藏
