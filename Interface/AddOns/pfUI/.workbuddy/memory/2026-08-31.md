## 剑刃乱舞与能量火花（用户提出）
- 官方机制：剑刃乱舞 = Mod Power Regen % (Energy) -20%，正规实现为每跳 +20→+16、间隔 2s 不变（DrinkWalk 注释同此）；energytick 的 +14~+22 窗口天然覆盖 +16，无需改窗口。
- 防御性增强（防 Turtle 按"间隔 2.5s"实现）：energytick.lua 加"节奏变化自适应重锁"——连续两次自然增量被容差拒绝且归一化 gap 彼此一致 → 判定节奏变了，采纳为新周期并重锚（f.energyLastRejectedNormMS 跟踪）；ENERGY_MAX_TICK_MS 2200→2600 以容纳 2.5s 变速。接受/重锚/ResetEnergyRuntime 均清除 lastRejected。
- 待实测：开剑刃乱舞观察火花是否跟随；关闭后应 2 个 tick 内重锁回 2s。
