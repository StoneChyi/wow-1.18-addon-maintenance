## 第四轮（~10:15）：合成提示缺法术描述（奉献案例）
- 现象：溢出 debuff（奉献）合成提示只有 名称/剩余/施法者，没有效果描述。
- 原因：Nampower SpellRec **不暴露描述字段**（只有 name/rank/dispel/school/spellIconID/rangeIndex，见 NampowerAPI.lua），原生 SetUnitDebuff 又定位不到溢出槽。
- 修法（DebuffSynthTooltip 升级，加 spellId 参数）：
  ① caster=="player" 时按名字（尽量对等级 rank 子串）遍历法术书 GetSpellName → `GameTooltip:SetSpell(idx, BOOKTYPE_SPELL)`（pcall + type 守卫）出原生完整提示，再补 层数/剩余 行；
  ② 通用路径 UF_GetSpellDesc：GetSpellRecField 候选字段探测（description/tooltipText/tooltip/description_lang），pcall+缓存（uf_spellDescCache，存原文或 false）。
- 导出 `pfUI.uf.SynthDebuffTooltip` 供 buff.lua 监控区复用（api 先于 modules 加载 ✓）。调用点三处都带 spellId（GetDebuffSlotEntry 取）。
- 注意：SetSpell 是 1.12 法术书提示（含消耗/施法时间），等级不对等时显示书中最高等级的描述，可接受。
- 两文件 SYNTAX OK；本轮未再备份（同日同主题，回滚可走 091138/100801 两份）。

## 第五轮（~10:25）：合成提示再精简（用户反馈"太多"+不要"由你施放"）
- 发现：SpellRec 确实有描述类字段（探测命中），但返回的是**未替换占位符的模板文本**（"造成So1点"、"在Sd内"）——不能用。
- 修法：删掉 UF_GetSpellDesc 探测与描述行；删掉「由你施放/由其他玩家施放」行。合成提示最终 = 名称(+等级) / 层数 / 剩余X秒/X秒；自己的法术在支持 SetSpell 的客户端才显示格式化完整描述。
- 结论：**SpellRec 的描述/tooltip 类字段是 DBC 模板原文（$o1/$Sd 占位符未替换），不要直接展示**。
