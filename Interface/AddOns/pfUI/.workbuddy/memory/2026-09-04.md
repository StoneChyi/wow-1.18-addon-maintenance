## 编号文字骑框：SetHeight(16) 居中陷阱（第七批补充 2，已修复）

**根因**：`f.group:SetHeight(16)` 把 8px 字体（描边约 10px）塞进 16px 文字盒。WoW 在高于字形的盒子里**垂直居中**画字，多出的 ~6px 平分上下 → 锚点"盒边贴框边"失效，文字视觉上跨在框体边缘。

**通用教训（WoW FontString）**：给 FontString SetHeight 超过字高，文字会在盒内垂直居中，"盒子锚定到边缘"就不再等于"文字贴着边缘"。做贴边标签时**永远不要撑大文字盒**；需要占位高度时用空 frame 承载，文字盒紧贴字形。

**偏移语义（修正文档）**：正值 = 推离框体（朝外），0 = 完全贴齐。早前报告写"正值朝框内"是错的，已改。
