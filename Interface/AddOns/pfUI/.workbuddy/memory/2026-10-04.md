## eqcompare：角色面板悬停自身装备时禁用无意义的自我对比
- 现象：按 C 悬停纸娃娃装备槽，仍弹出「当前装备」对比框，且对比对象就是同一件装备。
- 根因：`modules/eqcompare.lua` 的 `GameTooltipShow` 钩子只要提示里出现装备位置行就无条件弹 ShoppingTooltip，不判断悬停目标是否为自身已装备物品。
- 修复：钩子入口加 `GetMouseFocus()` 检测，鼠标焦点名为 `^Character.*Slot$`（角色面板装备槽按钮）时直接 return 跳过对比。背包悬停的对比行为不变。
- 备份：`modules/eqcompare.20261004_093912.selfcompare.bak`；luaparse 5.1 语法检查通过，grep 复验已落盘。
