## 固定位置姓名板「不显示」修复
- 根因：`nameplates.OnDataChanged` 在 `local visible = plate:IsVisible()` 后第 1299 行有
  `if not visible then return end`，此 `return` 早于 `plate:Show()`（1315 行）。
  之前把 `np` 改为挂到 `fixed_frame` 并由容器定位后，`UpdateFixedPlate` 仍维持
  「先 UpdateTargetFixedPlate() 再 fixed_frame:Show()」的顺序，导致跑 `OnDataChanged`
  时 `fixed_frame` 仍隐藏 → `np:IsVisible()` 为 false → 提前 return → `plate:Show()`
  永不执行，固定姓名板整块不显示。
- 修复三处（modules/nameplates.lua）：
  1. 缩放不再作用到容器 `fixed_frame`，改为采样 refScale（默认 1）后作用到 `np`：
     `np:SetScale(refScale * UIParent:GetScale())`，对齐真实姓名板有效缩放（plateScale × UIScale）。
  2. `np` 恢复直接锚定 `UIParent`（`np:SetPoint(anchor, UIParent, anchor, ...)`），
     不再移动容器定位，避免缩放叠加到容器坐标把 np 推离屏幕（已验证可渲染）。
  3. `UpdateFixedPlate` 显示顺序改为「先 Show 再写数据」：
     `fixed_frame:Show(); np:Show(); UpdateTargetFixedPlate()`。
     OnShow 已被 `_pfFixedPlate` 守卫，Show() 不会污染 visiblePlates/guidRegistry，
     也不会触发无数据的 OnDataChanged 崩溃。
- 校验：luaparse Lua 5.1 语法通过。逻辑依赖 WoW 运行时，需进游戏验证。

## 固定姓名板「没缩放/大小不一致」修复
- 根因：真实姓名板有效缩放 = 暴雪姓名板父框体缩放(plateScale) × UIScale。之前 `refScale`
  是「创建固定姓名板时临时采样 registry」。当目标超出屏幕、registry 里恰好没有其它可见
  姓名板时，采样为空 → refScale 回退 1 → 丢失 plateScale 这一层 → 固定姓名板「没缩放」。
- 修复（modules/nameplates.lua）：
  1. 新增模块级 `local lastPlateScale = nil`。
  2. 主循环 `for plate in pairs(visiblePlates)` 中，`plate:IsVisible()` 分支里每帧
     `lastPlateScale = plate:GetScale()`（plate 是暴雪 nameplate frame，非 np）。
  3. `CreateTargetFixedPlate` 里 `local refScale = lastPlateScale or 1`，替换掉现采样 registry 的循环。
  - 这样只要屏幕上出现过任意姓名板，lastPlateScale 就是正确的 plateScale，目标超出屏幕后
    固定姓名板仍能继承相同缩放，与真实姓名板尺寸一致。
- 校验：luaparse Lua 5.1 语法通过。

## 固定姓名板「仍是普通长宽，非目标缩放长宽」修复
- 关键：pfUI 的目标姓名板缩放 **targetzoom**（`cfg.targetzoom`/`cfg.zoomval`，默认 targetzoomval=.25
  → zoomval=1.25）**不是用 SetScale，而是直接在 OnUpdate 的 "Zoom animation" 里放大
  `nameplate.health` 血条的宽度/高度**：`wc = cfg.width*zoomval`，`hc = cfg.heighthealth*(zoomval*0.9)`。
  目标姓名板因此比普通姓名板大，而固定姓名板只复刻了 OnConfigChange 的普通尺寸 → 大小不一致。
- 修复（modules/nameplates.lua，UpdateTargetFixedPlate）：在 OnDataChanged 之前，按 targetzoom
  同步固定姓名板血条尺寸：
  ```lua
  local zoomW, zoomH = cfg.width, cfg.heighthealth
  if cfg.targetzoom then
    zoomW = cfg.width * cfg.zoomval
    zoomH = cfg.heighthealth * (cfg.zoomval * 0.9)
  end
  if np.health then
    if floor(np.health:GetWidth()+0.5) ~= floor(zoomW+0.5) then np.health:SetWidth(zoomW) end
    if floor(np.health:GetHeight()+0.5) ~= floor(zoomH+0.5) then np.health:SetHeight(zoomH) end
  end
  ```
  - 仅变化时才 SetWidth/SetHeight，避免每帧重设；固定姓名板不跑 OnUpdate，故需手动同步。
- 校验：luaparse Lua 5.1 语法通过。

## 补充：改为缓存真实目标血条实际尺寸（更精确复刻）
- 纯按 cfg 计算 targetzoom 尺寸仍可能不一致，改为直接缓存「目标姓名板血条的实际渲染尺寸」：
  1. 模块级 `local targetPlateW, targetPlateH = nil, nil`。
  2. OnUpdate 的 Zoom animation 之后（`if target and nameplate.health`）缓存
     `targetPlateW = nameplate.health:GetWidth()` / `targetPlateH = ...:GetHeight()`。
  3. UpdateTargetFixedPlate 里优先用 `targetPlateW or cfg.width`，缓存为空才回退 cfg 计算。
  - 这样固定姓名板精确复刻「目标超出屏幕瞬间」目标血条的真实大小（含 targetzoom 动画完成后的尺寸）。
- 校验：luaparse Lua 5.1 语法通过。

## 关键澄清：用户说的是「整个姓名板整体变大」，是 scale 不是血条 targetzoom
- 用户确认「目标姓名板被缩放」= 名字+血条+等级**整体等比变大**，即整体 scale，而非单纯血条变宽。
- 根因：目标姓名板有一个比普通姓名板更大的暴雪父框体缩放(frame scale)，而之前 `lastPlateScale`
  缓存的是「任意一个可见 plate」的 scale（可能拿到普通值），导致固定姓名板用普通 scale。
- 修复（modules/nameplates.lua）：
  1. 新增 `local targetPlateScale = nil`，在 OnUpdate 的 `if target` 分支里缓存
     `targetPlateScale = frame:GetScale()`（目标姓名板父框体缩放）。
  2. `CreateTargetFixedPlate` 的 refScale 改为 `targetPlateScale or lastPlateScale or 1`。
  3. `UpdateTargetFixedPlate` 每帧同步整体缩放：
     `np:SetScale((targetPlateScale or lastPlateScale or 1) * UIParent:GetScale())`（仅变化时）。
  - 同时保留 targetPlateW/H 血条尺寸缓存，最终固定姓名板 = 目标整体 scale + 目标血条尺寸，
    完整复刻目标姓名板（含 targetzoom 血条放大 + 整体 scale）。
- 校验：luaparse Lua 5.1 语法通过。

## 固定姓名板「没有光晕」修复
- 根因：光晕 `plate.glow`（targetglow 目标光晕）只在 `OnDataChanged` 里按
  `target and cfg.targetglow` 显示，尺寸由 OnConfigChange 一次性定为
  `width+60 × heighthealth+30`。固定姓名板不跑 OnUpdate 的 targetzoom 动画，
  且 health 被手动缩放到 `zoomW×zoomH`（含 targetzoom 放大），但光晕仍停留在
  基础尺寸 → 目标放大后血条+背板(backdrop)盖住偏小的光晕，导致看不到光晕。
- 修复（modules/nameplates.lua，UpdateTargetFixedPlate，OnDataChanged 之后）：
  显式按目标光晕配置强制显示并同步光晕尺寸到缩放后的血条：
  ```lua
  if cfg.targetglow then
    np.glow:SetWidth(zoomW + 60)
    np.glow:SetHeight(zoomH + 30)
    np.glow:Show()
  else
    np.glow:Hide()
  end
  ```
  - 光晕颜色仍由 OnConfigChange 的 `SetVertexColor(glowcolor)` 决定，此处只补尺寸+显示。
- 校验：luaparse Lua 5.1 语法通过。
