## pfUI 姓名板"堆叠不生效，需按 V 才生效"修复
- 症状：进游戏/login 姓名板堆叠（原生重叠分离）不生效，手动按 V 切换一次（隐→显）后才生效。新版 nameplates.lua 扫描器全量扫描的上一轮修复未解决。
- 根因（两份版本 overlap/init/OnCreate/OnConfigChange 代码基本一致，差异在新增逻辑）：
  1. overlap==0（默认）分支里 `nameplate.dwidth` 只在首帧缓存；登录首帧 pfUI Button 未布局，`GetWidth()` 返回 0 → dwidth 永久缓存 0 → 原生框被压成 0 宽 → 原生堆叠失效；按 V 重建后尺寸正确才恢复。
  2. 原生客户端堆叠系统按"姓名板被创建/重建"才重新评估，登录时已存在的框不被重新堆叠，只有销毁重建（手动 V）才触发。
- 修复（D:\twmoa_1172\Interface\AddOns\pfUI\modules\nameplates.lua）：
  1. overlap==0 分支改为仅当 `GetWidth()*scale > 1` 时才接管/缓存 dwidth，避免压成 0 宽。
  2. PLAYER_ENTERING_WORLD（首次）设置 `nameplates.forceRecreateT = GetTime()+0.6`；central OnUpdate 到点后以"先 HideNameplates 再下一帧 ShowNameplates"两阶段强制重建（`forceRecreatePhase`），模拟手动按 V，必须留帧间隔（同帧 Hide+Show 会被合并）。用 `recreateDone` 仅会话内首次触发，避免每次切图闪烁。
- 验证待用户游戏内 /reload 实测：进游戏直接面对怪物，堆叠应立即生效，无需按 V。

## 🔥 严重坑：gui.lua 自引用导致 pfUI 头像全部回退原生
- 现象（用户 /reload 后反馈）：pfUI 的 player/target/group/raid 等**所有头像框都变回暴雪原生**。
- 根因：`gui.lua` 的 `pfUI.gui.dropdowns` 是一个巨大表构造。我在表内给 `uf_threattexture` 写了一个 IIFE，里面引用了 `pfUI.gui.dropdowns.uf_bartexture`。
  **Lua 语义：表构造时先逐字段求值、构造完成最后才把表对象赋给 `pfUI.gui.dropdowns`** —— 所以 IIFE 执行那一刻 `pfUI.gui.dropdowns` 还是 nil（或指向旧表，旧表无 `uf_bartexture`），`pfUI.gui.dropdowns.uf_bartexture` 触发 nil 索引崩溃（`attempt to index field 'dropdowns' (a nil value)`）。
- 放大机制（致命）：`pfUI:LoadModule`（pfUI.lua:291-294）**没有 pcall 保护**，直接 `pfUI.module[m]()`；模块在 ADDON_LOADED 里按 `for _, m in pairs(this.modules)` 顺序执行（顺序 = modules.xml 的 Include 顺序）。`gui.lua` 排第 2（在 player.lua(17)/target.lua(19)/group(25)/raid(26) **所有头像框之前**）。GUI 模块这一崩溃**中断了整个 LoadModule 循环**，后续所有 unit frame 模块都不执行 → TargetFrame/PlayerFrame 等没被 Hide、pfUI 框没创建 → 全部原生框漏出。
- 修复（gui.lua）：
  1. `uf_threattexture` 的 IIFE 改为**不引用 `pfUI.gui.dropdowns` 自身**：标准 7 项纹理内联为局部 `std` 表，再追加 CustomMedia A–Y（保持动态生成）。
  2. Target 段三个设置项的 ufunc 原直接传 `pfUI.uf.target_threat_apply`（该全局在 target 模块加载后才赋值，GUI 构建面板时还是 nil → 实时生效失效）；改为**延迟引用闭包** `applyThreatBox()`（用户改设置时再取 `pfUI.uf.target_threat_apply`），保证材质/长宽改动实时生效。
- 教训（长期）：在 `pfUI.gui.dropdowns = { ... }` 这个大表**构造内部**，绝不能用 `pfUI.gui.dropdowns.xxx` 自引用（含 IIFE）。需要复用内部字段时，要么内联，要么等表闭合后在表外 `pfUI.gui.dropdowns.xxx = ...` 追加赋值。另外：`LoadModule` 无 pcall，任何模块（尤其排在 unit frames 之前的 gui/unlock/hoverbind/actionbar 等）的**加载期运行期错误都会连累所有头像框**，改这些前置模块务必 luaparse 校验 + 谨慎。
- 验证：luaparse（luaVersion 5.1）校验 gui.lua/target.lua/profiles.lua 语法全部 OK；需用户 /reload 实测头像是否恢复、Target 页材质/长宽设置能否实时生效。
