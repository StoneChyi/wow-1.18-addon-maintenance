## 2026-08-31 补丁：energytick.lua:64 tonumber 多返回值报错
- `tonumber(UnitStat("player", 2))` 嵌套调用把 UnitStat 全部返回值 (base, effective, posBuff, negBuff) 传给 tonumber，第二个返回值当 base → "bad argument #2 to 'tonumber' (base out of range)"。
- 修复：先 `local rawAgi = UnitStat("player", 2)` 再 tonumber(rawAgi)。与 DrinkWalk 的 UnitPowerType hotfix 同一模式。
- 教训入 MEMORY：**任何 1.12 多返回值 API 严禁作为唯一实参嵌套进另一函数调用**，必须先捕获首返回值到局部变量。同类高危 API：UnitStat、UnitPowerType、UnitManaMax?（UnitMana/UnitManaMax 单返回）、GetTalentInfo、UnitClass。
