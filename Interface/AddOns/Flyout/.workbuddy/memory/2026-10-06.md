## Flyout 左键直用第一个动作修复
- 需求：动作条宏 `/flyout 制造邪能石;51934;制造火焰石;51932;制造虚空石;制造愤怒石;制造法术石` 左键点按钮 = 直接施放第一个「制造邪能石」。
- 根因：main.lua 末尾原用 `hooksecurefunc("UseAction", ...)` 实现，但 Turtle 1.12 客户端原生无 hooksecurefunc（2.0+ API），且 pfUI 加载晚于 Flyout（按字母序），加载时报 nil 错误 → 挂接从未生效。
- 修复：抽出 `Flyout_OnUseAction(slot)`；加载时若有 hooksecurefunc 则用它，否则手动包裹全局 UseAction 兜底（保存原函数 → 调原函数 → 再调 Flyout_OnUseAction）。
- 行为：左键点栏按钮=用第一项（技能 CastSpell / 宏 / 物品，物品优先找同名宏否则 MPUseItemByName）；右键或悬停=弹菜单；sticky 不直用。
- 校验：luaparse 5.1 SYNTAX OK。备份 backup/main.lua.20261006-1049。
