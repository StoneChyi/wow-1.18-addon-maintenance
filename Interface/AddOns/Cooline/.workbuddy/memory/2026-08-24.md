# 2026-08-24

## Cooline 性能优化（Cooline.lua）
针对冷却条的 3 个性能热点做了最小改动：
1. **拆分全量重扫**：`detect_cooldowns()` 拆成 `detect_item_cooldowns()`（背包+装备，响应 `BAG_UPDATE_COOLDOWN`）与 `detect_spell_cooldowns()`（技能书，响应 `SPELL_UPDATE_COOLDOWN`）；`start_cooldown` 提升为共享函数。事件改为经 `request_item_rescan`/`request_spell_rescan` 走 0.1s 防抖（`cooline.rescan_timer`），合并战斗连发事件，消除 CPU 尖峰。
2. **去掉 O(N²) 去重**：删除 `start_cooldown` 内按 `end_time` 浮点相等遍历 cooldowns 的循环（已按 name 作 key 去重，原逻辑还会误杀同名不同时长冷却）。
3. **层级排序每帧只排一次**：`on_update` 每帧 `getKeysSortedByValue` 一次并建 `levelMap`，`update_cooldown` 直接查表（原逻辑每个临近结束的冷却都全表排序）。

注意：防抖带来最多 0.1s 的冷却显示延迟（可忽略）。`detect_cooldowns()` 仍保留供 `VARIABLES_LOADED` 初始化同步全扫。

## 无 SuperWoW 回退路径 tooltip 扫描优化（Cooline.lua, `if not ZMD_HAS_SUPERWOW` 块）
原 `UseAction` 钩子每次点击动作条都做一次 `SetAction` tooltip 扫描（较重）。改为：
- 加 `ZMD_actionNameCache[slot]` 缓存槽位→法术名，`ZMD_GetActionSpellName` 命中缓存直接返回，仅未命中时才 `ZMD_ScanActionName`（SetAction+GetText）。
- 扫描后 `ZMD_scanTip:Hide()` 释放 tooltip。
- 监听 `ACTIONBAR_SLOT_CHANGED` / `ACTIONBAR_PAGE_CHANGED` / `PLAYER_ENTERING_WORLD`，变化时清空整张缓存（下次点击按需重扫），避免每帧/每次点击扫描。
- 仅影响无 SuperWoW 环境（当前客户端有 SuperWoW，不执行此分支）；SuperWoW 路径仍走 `UNIT_CASTEVENT`，未动。

## 修复：走马灯"显示技能名"开关无效（Cooline.lua）
根因：显示技能名在 `ZMD_SpawnIcon` / `ZMD_ApplyName` / `ZMD_ApplyDimensions` 三处都加了 `cooline_theme.height >= 24` 门槛，而 `settings.lua` 条高默认 18，导致默认条高下勾选"显示技能名"永不生效（表现为"启用无效"）。名字文本框挂在图标下方（`TOP`→`BOTTOM` -2），本不依赖条高。已移除这三处高度门槛（及 `ZMD_CreateIconFrame` 创建时的隐藏条件、`/zmd` 帮助文字里的"条高≥24"说明），使开关独立生效。
