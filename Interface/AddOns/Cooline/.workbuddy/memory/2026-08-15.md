# 2026-08-15

## Cooline 插件（WoW 1.12 经典旧世）

- 修复报错 `attempt to call method 'SetShown' (a nil value)`：WoW 原生 Frame 无 `SetShown` 方法（那是 AceGUI 的）。将 4 处 `cooline:SetShown(...)` 改为已有方法 `cooline.set_shown(...)`（内部走 `Show()`/`Hide()`）。位置：`VARIABLES_LOADED` 显隐初始化 + `/zmd cooline` 命令分支。
- 新增 `/cl`（别名 `/cooline`）配置面板，追加在 `Cooline.lua` 末尾（~第 997 行起）。面板含：冷却条（显示开关/闪烁提示/垂直方向/反向/宽度/高度/阈值）与走马灯（启用/技能名/方向/速度/存活时间），改动即时生效。
- 关键点：面板代码追加在同一 chunk 内，才能访问 `local cooline`、`local ZMD_ApplyDimensions`、`ZMD_ApplyName` 等局部变量；控件全部使用唯一全局命名（`CL_NewName` 计数器），避免 `OptionsSliderTemplate` 的 `$parent` 命名冲突。
- 注意事项：`cooline.apply_theme()` 里对 `ZMD_ApplyDimensions` 的调用因作用域问题（定义早于 ZMD_ApplyDimensions 的 local 声明）实际是 no-op，配置面板里宽度/高度改动是额外显式调用了 `ZMD_ApplyDimensions()` 来补偿。

## 二次调整（同日晚些）

- 修复报错 `SetPoint`：本客户端（1.12）**不接受单参数** `SetPoint("CENTER")`，报 `Usage: ...:SetPoint(...)`。改为 `SetPoint("CENTER", 0, 0)`（与 `cooline:SetPoint('CENTER', x, y)` 一致的三参数「point + 偏移」形式）。
- 按用户要求把配置面板从 `Cooline.lua` 迁到 `settings.lua`。为跨文件访问，把 `cooline`（原 local）、`ZMD_ApplyDimensions`、`ZMD_ApplyName`（原 local function）改为全局；`ZMD_ApplyRelativeOffset` 保持 local（面板不用它）。
- 副作用（良性）：`cooline.apply_theme()` 里的 `if ZMD_ApplyDimensions then` 现在能正确命中全局函数了，即改动主题时走马灯会同步 resize，此前那条 no-op 问题顺带被修复，故面板宽度/高度处理不再需要额外显式调用 `ZMD_ApplyDimensions()`。
- 文件结构：`settings.lua`（先加载）= 主题/忽略表 + 配置面板；`Cooline.lua`（后加载）= 冷却条 + 走马灯逻辑。面板代码只在 `/cl` 运行时才访问 `cooline` 等全局，无加载顺序问题。

## PFUI 美化配置面板

- 面板背景改为 PFUI 扁平风：`CL_Backdrop()` 惰性判断 `pfUI.backdrop`（存在则直接复用，完美匹配 pfUI 的 1px 光边）；未装 pfUI 用 `WHITE8X8` 底 + `UI-Tooltip-Border` 边兜底。
- 关键坑：**不能**在 settings.lua 顶层判断 `pfUI`，因为按字母序 `Cooline`(C) 先于 `pfUI`(p) 加载，顶层时 `pfUI` 还是 nil；必须在 `/cl` 打开面板时（运行时）判断。
- 配色：背景 `(0.07,0.07,0.07,0.9)`，边框 `(0.3,0.3,0.3,1)`。
- 新增 `CL_Divider(parent,y)` 画 1px 分隔线（WHITE8X8 + SetVertexColor），放在标题下、两个 section 下。
- 注：复选框/滑块/按钮用的是标准模板（UICheckButtonTemplate/OptionsSliderTemplate/UIPanelButtonTemplate），装了 pfUI 会被其 Skinner 自动扁平化，无需手动处理。

## PFUI 美化 v2（改用 penv 环境，参考 Automaton 写法）

- 弃用「直接复用 `pfUI.backdrop`」，改为 `pfUI:GetEnvironment()` 拿 penv，用官方皮肤函数手动美化：`CL_SkinWindow`(StripTextures + CreateBackdrop)、`CL_SkinButton`(StripTextures + 清 Left/Middle/Right + SkinButton)、`CL_SkinCheckbox`(SkinCheckbox(cb,18))、`CL_SkinSlider`(SkinSlider，防御性判断存在)。
- 关键 API 签名：`penv.CreateBackdrop(frame, parent, border, alpha)`——Cooline 面板传 `border=true, alpha=0.9`；`SkinCheckbox(cb, 18)`；`SkinButton(btn)`。
- 顺序坑：`CL_SkinWindow(cl_frame)` 必须在**创建 title/divider 等子控件之前**调用，否则 `penv.StripTextures` 会把后画的 divider 纹理也清掉（所以放在 `cl_frame:Hide()` 之后、`local title=...` 之前）。
- 面板懒创建（`/cl` 时），故无需像 Automaton 那样挂 ADDON_LOADED/PLAYER_LOGIN 事件等 pfUI 就绪——运行时 pfUI 必已加载。

## ESC 关闭面板

- 报「按 ESC 不能退出」：自定义面板需把全局帧名注册进游戏 `UISpecialFrames` 表，ESC 才会去关闭它（否则 ESC 直接开游戏菜单）。修复：在 `CL_CreatePanel` 里 `cl_frame` 创建后加 `tinsert(UISpecialFrames, "CoolineConfigPanel")`（帧名须为全局名，`CreateFrame("Frame", "CoolineConfigPanel", UIParent)` 已满足）。
