## WIM 设置失效 bug 修复（弹窗 / 拦截斜杠命令）
- 现象：`发送私聊时弹出窗口`(popOnSend) 与 `拦截私聊斜杠(/)命令`(hookWispParse) 两个设置勾选无效。

- 备份：backup/WIM_Hooks.lua.20260915-190041.bak；luaparse 校验通过。
- 实测要点：设置里关"拦截私聊斜杠命令"后 `/w 名字 内容` 应直接发出不弹窗；开拦截则弹窗（原设计）。popOnSend 关闭时从 WIM 窗口/直接发送不再弹窗，开启时弹窗。
