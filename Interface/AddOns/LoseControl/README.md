# LoseControl 插件使用说明

## 简介

LoseControl 是一个显示玩家受到控制效果的插件，当你被眩晕、沉默、定身或减速时，会在屏幕上显示一个图标并倒计时。同时，它还具有在被闷棍时自动喊话的功能。

## 命令列表

所有命令都以 `/lc` 开头，以下是可用的命令：

### 基本命令

- `/lc` - 开启/关闭自动喊话功能
- `/lc unlock` - 解锁图标，使其可见并可拖动
- `/lc lock` - 锁定图标并隐藏

### 自定义设置

- `/lc size <数值>` - 设置图标大小，数值范围为 20-200
  - 例如：`/lc size 60` 将图标大小设置为 60 像素
  
- `/lc alpha <数值>` - 设置图标透明度，数值范围为 0-1
  - 例如：`/lc alpha 0.8` 将图标透明度设置为 80%

## 图标颜色说明

图标边框颜色表示不同类型的控制效果：

- **红色** - 眩晕、击倒等硬控制
- **蓝色** - 沉默效果
- **橙色** - 定身效果
- **灰色** - 减速效果

## 使用建议

1. 首次使用时，输入 `/lc unlock` 解锁图标
2. 将图标拖动到合适的位置
3. 使用 `/lc size` 和 `/lc alpha` 调整图标大小和透明度
4. 完成设置后输入 `/lc lock` 锁定图标

## 注意事项

- 开启自动喊话功能后，被闷棍时会自动在说频道发送"被闷棍了！"的消息
