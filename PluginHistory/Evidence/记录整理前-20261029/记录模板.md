# 插件记录模板

将下面条目复制到对应插件页“逐次修改记录”的最上方，替换所有占位内容。编号按同一插件当天已有记录递增；日期用实际修改或确认日期。未确认原修改日期的旧内容保留在早期汇总。

```markdown
<a id="change-插件名-YYYYMMDD-01"></a>

### YYYY-MM-DD｜简短说明本次变化

- 记录编号：`插件名-YYYYMMDD-01`
- 记录类型：修改
- 游戏验收：待游戏验收
- 对应提交：随本条记录一并提交（见本页 Git 历史）

- 修改原因：实际遇到的问题或用户需求。
- 修改内容：具体改变的行为；有前后差异时写清。
- 涉及文件：代码、资源、依赖和必要的删除。
- 关联功能：相关插件、界面、配置或加载顺序。
- 检查结果：实际执行的检查、环境、结果及限制。
- 游戏验收与未确认：已确认的范围、尚待确认的场景。
- 替代关系：如替代或撤回旧方案，引用旧记录编号；无则省略。
```

记录类型和验收状态的允许值见[记录规范](记录规范.md)。补充游戏反馈时新增“实测反馈”条目，写明确认日期、原记录编号和实际范围，不把旧条目改写成当时已经完成验收。

新建插件文件时使用以下四部分，证据状态与 `maintenance-index.json` 一致：

```markdown
# 插件名 修改说明

[插件修改记录](README.md) · [记录规范](../记录规范.md) · [本页 Git 历史](https://github.com/StoneChyi/wow-1.18-addon-maintenance/commits/main/PluginHistory/Plugins/插件名.md)

## 插件概况

- 插件：`插件名`
- 维护状态：**有维护记录**

## 当前维护摘要

当前保留的个人修改或本次新增插件的交付范围。

## 逐次修改记录

在此插入填写完成的条目。

## 早期历史汇总与维护依据

没有可靠的早期记录时明确写出，不推断官方原版或作者。

### 待补充

尚需取得的来源、历史或游戏验收。

### 依据

真实来源、研究报告或已有提交链接。
```
