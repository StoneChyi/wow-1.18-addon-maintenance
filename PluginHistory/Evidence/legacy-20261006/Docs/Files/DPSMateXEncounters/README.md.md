+# DPSMateX 战斗分类
+
+在 DPSMateX 原来的时间选择菜单中加入 **Boss汇总**、**小怪汇总**。每个窗口独立选择，沿用原统计模式、筛选和详情入口。
+
+## 启用
+
+完全退出游戏并重新启动，在角色选择界面的插件列表中启用 **DPSMateX 战斗分类**（目录 `DPSMateXEncounters`）。新目录通常不能仅靠 `/reload` 发现。
+
+依赖 DPSMateX；治疗与实际吸收、成功施放汇总需要同时启用 DPSMateXInsights。分类使用现有 Nampower 战斗事件和 GUID 接口，不另开扫描计时器。
+
+右键打开原窗口菜单，在原时间选择位置选择 Boss汇总或小怪汇总。没有数据时主栏保持空白。新增治疗数据条继续只显示数值、占比，不加入 HPS。
+
+## 统计口径
+
+- Boss汇总：本周期所有已确认有首领参与的战斗，包括未击杀、团灭和增援数据。
+- 小怪汇总：已确认普通敌方 NPC 参与、没有首领证据的 PvE 战斗。
+- 未分类：PvP、无法确认单位，以及没有 Boss 证据的重载/跨区域中断。内部保存，可用 `/dpsxenc` 查看场数，不强行计入小怪。
+- 从启用分类或上次清空数据开始累计；不推算安装前的旧历史。
+- 时长为实际战斗时长之和，手动分段保留同一遭遇，只计一场；离线时间不计入。
+- 确认 Boss 后，整场及此前手动切片一起归入 Boss。仅选中或经过首领、旁观其他队伍的战斗不会标记。
+- 沿用 DPSMateX 的队伍脱战规则，不因玩家自己短暂脱战结算。
+- 删除历史、只保存 Boss 历史、历史数量裁剪都不减少累计。原来的“清空全部数据”同时清空分类；单独新建分段继续当前遭遇。
+- 原全程包含启用前数据和战斗外治疗，因此不要求原全程等于 Boss＋小怪。
+
+## 首领识别
+
+敌对 `worldboss` 单位与自己、队友或其宠物发生有效战斗事件时，标记首领。副本内为少数常见普通精英首领提供明确名称补充：瑞文戴尔男爵、黑暗院长加丁、达基萨斯将军、戈多克大王、瑟莱德丝公主、达格兰·索瑞森大帝、艾德温·范克里夫、阿扎达斯（中英文）。不把 Babble-Boss 字典中的普通怪自动当成首领。
+
+普通精英型或服务器自定义首领可能需要补充名单。进入副本、选中该首领后输入 **`/dpsxenc boss`**；名单按区域＋名称保存。建议开战前补充；若已开战，需要之后有一次相关战斗事件才能重新确认。名单保留到清空统计后。
+
+## 支持范围
+
+| 模式 | Boss / 小怪汇总 |
+| --- | --- |
+| 伤害、DPS、承伤、DTPS、敌方伤害/承伤、友伤 | 支持 |
+| 总治疗、有效治疗、过量治疗及承疗模式 | 支持 |
+| 新增治疗与实际吸收、成功施放 | 支持 |
+| 动作回放、死亡、打断、驱散、光环、仇恨、旧吸收及旧治疗吸收模式 | 保留原范围；选中累计范围时切回当前战斗 |
+
+详情沿用原界面，并注明累计范围和场数。技能、目标、次数及金额可以累计；单场曲线、逐条审计、动作时间轴不拼接为累计时间轴，查看这些内容请选当前或历史战斗。累计范围的旧详情曲线位置显示简短说明；原饼图和数据明细继续使用。
+
+## 性能与保存
+
+使用现有采集结果，只在结算/手动分段时合并统计，不复制原始事件、动作回放和逐秒曲线。战斗中仅对请求的统计类别生成视图，每秒最多刷新一次，最多缓存四个视图；队伍原数据和历史不被该视图修改。空闲时不扫描单位。
+
+GUID 缓存最多256项，宠物归属短期缓存；调试日志最多200条，默认关闭。每层目标明细最多64项、技能明细最多128项；整个汇总达到10000个技能明细后新增技能归入“其他”，每个已有父项可能额外保留一个“其他”项。新增模块每技能目标最多16项。超限时金额、次数仍累计，并在新详情注明明细压缩；被压缩的数据无法恢复原目标/技能的精确筛选。不同玩家的累计姓名仍随统计周期增加。
+
+待解析名字最多等待2秒；切换战斗前强制处理原场待解析事件，未解析项目计入原模块的 missed 计数，不会写到下一场。
+
+保存变量独立为 `DPSMateXEncountersDB`（每角色）。完整数据清空仍由 DPSMateX 原有流程负责。禁用本模块后，已保存的 Boss/小怪窗口选择自动回到当前战斗，避免旧模块读取无效范围。
+
+命令：`/dpsxenc` 查看三类场数/时长；`/dpsxenc debug` 开关有上限的分类日志；`/dpsxenc boss` 添加当前副本目标到首领名单。
