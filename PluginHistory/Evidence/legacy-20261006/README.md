# 2026-10-05～06 插件最新版备份与迁移资料

此目录备份截至快照时间的当前磁盘最新版，保留两天累计修改，不是每一轮中间版本。

- `Latest/Interface/AddOns/`：18 个完整插件目录，可用于完整回退。
- `Settings/WTF/`：相关插件保存变量、宏、按键和启用列表；并非整个 WTF。
- `Baseline/Interface/AddOns/`：逐文件最早可确认的修改前快照。
- [适配指南](Docs/适配指南.md)：功能迁移入口、依赖、配置与验收。
- [详细代码修改索引](Docs/详细代码修改索引.md)：各文件的全部增删代码、行号、声明锚点及基线来源。
- `Patches/`：总补丁、按插件补丁和按文件补丁。
- `Evidence/`：旧备份、原补丁、变更说明和已有检查脚本。
- `Manifest/`：SHA-256、文件与基线记录。

回退前退出游戏，先另存更新后的插件目录；将目标旧插件目录整体恢复，避免仅覆盖文件后留下新版多余文件。不要把 Baseline、Patches 或 Evidence 复制进 AddOns。Settings 只在需要恢复旧配置时单独恢复，避免覆盖后续游戏进度。

迁移到新版时，应合并功能改动并验证，不能直接把旧 Lua 整文件覆盖到新版。现有阶段补丁不能不分顺序全部执行。

注意：保护了昨天改过的 Cat、TianYan、Outfitter 和今天的 16 个目录（Cat 重复计一次）。CatPotion 为今天安装，PlayTurtle 仅分析；不计入自行修改目录。
