# DPSMateX 紧凑详情与图表开销优化

修改日期：2026-10-06。

已修改游戏目录中的插件，重新加载界面后生效。

## 界面变化

- 32个原详情脚本及对应布局移除时间折线、堆叠图、比较时间图，以及仅用于时间图的切换、触发筛选和曲线选择控件。
- 伤害、治疗等典型个人详情由1000×600收紧为1000×350，饼图、技能列表、命中/暴击等数字表向上移。总览保持原有列宽和数值表，移除绘图用玩家勾选框。光环详情保留上下两个覆盖率数值表，按实际被移除的200高度缩短窗口，避免内容超出边框。
- 治疗与实际吸收详情采用相同的1000×350窗口、245/345/380三栏比例、背景边框与黄色文字。左侧饼图，中间图标列表，右侧合计、总治疗、有效治疗、过量、实际吸收、次数、平均贡献及吸收占比。不增加HPS展示或跨模块切换按钮。
- 治疗详情左键技能选择数值，右键技能或“目标”按钮查看对应目标；保留搜索、来源/目标类型筛选、治疗口径切换、分页、比较和手动刷新。无数据时列表空白。
- 首领与小怪汇总继续使用相同统计入口和范围标题，不再创建图表占位说明。

## 消耗变化

- 从原详情删除排序、汇总、坐标构造、触发标记、折线/堆叠图的创建与更新代码。
- DamageDone、DamageTaken、EnemyDamage、Healing和HealingTaken停止创建及写入技能叶子的逐秒金额表；累计金额、次数、命中/暴击、最小/最大值与战斗时间保留。
- 金额时间采样的同步发送入口不再排序或构造曲线数据包；仍兼容旧客户端传入的时间信息以保留战斗时长，累计技能数据同步保持原格式。
- 新治疗模块删除AddBin及其调用，停止逐秒采样；累计金额和实际吸收归属不变。
- 加载时一次性释放旧金额曲线采样；仅按明确的数据结构清理技能叶子。父级数值总计、死亡、打断、驱散、光环覆盖率、吸收归属和动作回放事件不被该清理修改。
- 新治疗饼图最多12个主要项目加“其他”，总占比保留；分布未变时复用图表。窗口、数值表和列表行复用，没有增加每帧绘图或自动刷新。

## 验证

- 130个Lua文件编译检查通过，32个修改后的XML布局解析通过。
- 32个原详情模块的打开、再次打开及比较入口在模拟UI中通过；数值网格不因重复打开而重复创建。
- 29项Insights回归检查通过，含治疗/吸收归属、回放、图标、空数据、布局边界、饼图上限与复用、刷新选中数值和旧采样清理。
- 23项首领/小怪汇总回归检查通过。
- 实际原采集函数连续执行两万条金额写入，累计金额、计数及最小/最大值保持正确，未生成逐秒采样表。
- 原窗口锁定回归检查通过。

上述为离线检查。未测量真实游戏画面、客户端原生对象内存或FPS，因此不能给出实际提升百分比。
