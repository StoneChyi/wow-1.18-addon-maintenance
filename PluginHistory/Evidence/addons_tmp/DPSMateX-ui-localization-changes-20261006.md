# DPSMateX 详情布局与中文界面修改

常规伤害、治疗、吸收等详情及对比窗口从 1000×350 调整为 880×450，三栏同步缩窄，列表与数值表增加行高，图标保持正方形并垂直居中。部分总览窗口按原宽度比例调整；原本较高的光环详情保留尺寸。折线图及逐秒金额采样继续停用。

治疗与实际吸收详情采用相同的窗口比例和三栏风格。中间移除上一页、下一页和页码，改用原生 FauxScrollFrame 滚动条与鼠标滚轮，复用 11 个行控件，保留搜索、来源筛选和右键查看目标。

右侧改为命中、暴击、吸收的次数、占比、平均值、最小值和最大值表，使用原治疗表的蓝色/橙色进度条。总治疗/有效治疗切换会同步改变治疗数值口径，吸收仍为实际金额。记录 critical 标记并保存固定分类累计值和极值，不新增逐秒采样或每帧刷新。同名技能、宠物、目标和首领/小怪汇总保留这些分类统计。旧记录缺少分类标记时显示“未分类”，不补造暴击数据。

修复中文脚本访问已删除的触发筛选控件，导致后续命中、暴击及玩家菜单汉化中断的问题。补齐设置中的字体、描边、纹理、背景、边框层级、报告频道选项的中文显示。只翻译显示文字，保留存档键、资源路径、频道标识和玩家名字。

验证：131 个 Lua 文件编译通过；32 个原详情窗口打开/对比检查通过；修改后的 XML 及其内嵌脚本检查通过；30 项 Insights、24 项 Encounters 检查通过；完整中文加载与菜单检查通过；金额采样停用和窗口锁定回归检查通过。滚动条拖动、滚轮、列表边界、控件复用、命中/暴击合并及历史兼容均经模拟验证。未在实际游戏内验证画面或帧率。
