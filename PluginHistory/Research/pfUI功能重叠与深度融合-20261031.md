# pfUI 功能重叠排查与第二轮深度融合

核对日期：2026-10-31。依据为当前安装目录、TOC 实际加载清单、当前使用角色的最新本地保存配置及源码；未复制账号目录、角色存档或登录数据。本地只读配置快照不保证下一次游戏运行状态不变。

## 排查方法与结论

当前共有 92 个有效同名 TOC 入口。启用表中有历史残留名称，未列出的插件也不能直接判为停用；例如 pfUI 有近期有效保存配置。因此分别核对“目录存在、代码确实加载、功能开关开启、是否实际同职责”。菜单隐藏不等于模块停用；满级时旧经验条隐藏，也不代表其经验事件已停止。

| 功能 | 本地核对结果 | 本轮处理 |
| --- | --- | --- |
| 经验条 | pfUI 与 Automaton ExpBar 都处理经验；旧条满级自行隐藏 | 合并统计、事件和显示到 pfUI 原生经验条，保留双倍、速率、升级时间及同等经验次数估算 |
| 鼠标提示 | pfUI 与 Automaton Tooltip 重复包装提示方法；后者还有大量独有内容 | 共用 libtooltip 内容上下文与 pfUI 绘制流程，保留原模块作为数据提供者 |
| Shift 角色链接 | pfUI 与 InterPlayerLink 重复拦截；PlayerLinkEnhance 另有独有点击动作 | 合并到 pfUI 聊天的单一动作分发，旧 InterPlayerLink 在托管时不再挂接 |
| 背包银行 | Bagshui 使用中，pfUI 背包已停用 | 保留分类、离线数据、搜索与规则，不强行换回 pfUI 背包 |
| 治疗团框 | NotGrid 使用中，pfUI 队伍／团队框体不显示 | 保留治疗操作和指示器；没有双团框可直接停用 |
| 物品增强 | S_ItemTip 的商价／物品ID入口已关闭，其他装备及跨角色信息仍有用途 | 保留其独有信息；不因同属提示框而停整包 |
| 冷却数字 | pfUI 冷却开启；旧 OmniCC 源文件没有列入 Automaton TOC，独立旧目录不存在 | 不把未加载源码误计为重复执行 |
| Cooline | 时间轴和闪烁提醒，区别于按钮倒计时 | 保留 |
| 战斗数据 | DPSMateX、TWThreat、EavesDrop 分别承担统计、仇恨、日志；另一统计条停用 | 保留各引擎；pfUI thirdparty 只是外部面板适配 |
| 战斗提醒 | 原模块进入战斗声音与 pfUI 画面提醒没有同时开启 | 保留声音，无需因分类相似而关闭 |
| 姓名板 | 主城头顶名字控制与 pfUI 姓名板绘制职责不同 | 保留当前分工 |
| 信息条 | pfUI 数据槽已让位，diminfo 还有个人传送与副本记录等功能 | 保留 diminfo |
| 独立资源条 | 两侧独立条功能均未运行 | 不制造不存在的双开问题 |
| 自动任务 | 自动任务业务与 pfUI 任务界面皮肤不是同一功能 | 保留任务自动化及自定义任务规则 |
| 批量购买 | pfUI 已内置，旧启用表中的独立目录已不存在 | 无第二个执行引擎可删除 |
| CleanChat | 有共同聊天装饰，但关键词、重启、硬核、掷骰与副本消息等仍有独有处理 | 本轮保留；没有声称整模块可被 pfUI 等价替代 |

## 本轮实际融合

### 提示内容

- libtooltip 负责统一捕获物品、单位、技能与直接文字内容；保留物品 ID、物品链接、数量三个原读取接口。
- pfUI 负责布局与刷新；原 Tooltip 模块提供护甲抗性、伤害攻速、采集、声望、愿望、印象、宠物及法术 ID 等信息，不再独立重复包装所有提示方法。
- 物品 ID 以 pfUI 开关为唯一托管设置，首次按原开启状态合并；其余独有选项沿用原存档。新增“鼠标提示→增强信息”原生页，原页调整为“常规”子页。
- 保留战斗隐藏及 Shift 临时查看、光标缩放、框体名称观察和原单位框提示策略。退出托管恢复独立内容路径，避免物品 ID 双显。
- 修复共享提示上下文残留及刷新重入；使用兼容 Lua 5.0 的返回值展开，不能依赖 Lua 5.1 才有的 unpack 起止参数。

### 经验统计

- 一套会话统计驱动 pfUI 原生经验条及鼠标提示；补齐升级事件顺序、零经验／零时长、载入地图、满级声望切换等边界。
- 保留经验速率、预计升级时间和最近一次经验换算次数；次数明确包含任务等经验，不误称准确击杀数。
- 旧 ExpBar 在托管后停止事件和显示。已有原生条布局、文字显示选择及声望条保持；统计文字另设开关，默认不强行添加外置文字。
- 首次仅在旧条开启而原生条关闭的冲突配置下保留开启意愿，后续不覆盖用户选择；原位置与独立存档保留供回退。

### 角色链接与点击动作

- pfUI 角色链接插入并入原聊天链接处理，不再额外挂一层同功能拦截；PlayerLinkEnhance 调用同一动作分发。
- 好友、忽略、公会与团队邀请弹窗填名优先于聊天插入；Who、Ctrl 目标、Alt 取名、右键菜单及普通私聊继续保留。
- 统一解析带行号后缀的角色链接；支持两种插件加载顺序。托管时 InterPlayerLink 停止独立挂接，关闭托管恢复原启停意愿。
- PlayerLinkEnhance 的头像菜单、权限判断和其他独有逻辑保留。

## 验证与边界

新增经验条、提示共享流程、提示原生设置及角色链接测试，结合既有设置页、商人交接和头像菜单回归；具体真实结果见对应插件的最新维护条目。

这些检查采用实际插件源码和受控游戏接口模拟，Lua 5.0 编译另行执行。实际世界物件提示、第三方附加提示的视觉叠加、鼠标命中及服务器事件仍待游戏验收。没有删除插件目录，没有直接改写 WTF，没有宣称所有相近功能都能等价融合。Automatonex 与 PlayerLinkEnhance 仍提供保留的独有能力。
