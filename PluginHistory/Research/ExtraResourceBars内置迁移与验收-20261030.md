# ExtraResourceBars 内置迁移与验收

日期：2026-10-30。用户要求把生命条及其他必要功能内置 pfUI，保留现有设置与习惯，确认完整后才停用独立版；资源色进一步调整为跟随玩家头像实际配色。

## 当前完成与停用边界

已新增 pfUI 内置兼容模块、兼容设置面板和全部依赖材质；默认不启用试用。没有删除、修改、停用独立 ExtraResourceBars，没有编辑任何 WTF、角色插件开关或布局缓存文件，也没有执行 DisableAddOn。

首次导入是游戏内对当前角色的操作：复制旧设置，读取现有两条的实时位置和缩放，保存到 pfUI 自己的角色配置。未编辑原表 ERB_options；已编辑的内置设置不会被再次导入覆盖。旧版未加载时先保持它启用，进入角色后再导入，避免把预览默认值当成旧布局。没有把真实角色设置复制到仓库；离线测试全部采用合成数据。

## 功能对应

| 功能 | 内置兼容行为 |
|---|---|
| 生命/当前资源 | 各有独立条；生命固定色或红黄绿渐变；资源随 UnitPowerType 切换，修复中文德鲁伊首次着色问题及最大法力事件遗漏。 |
| 原39项设置 | 保留原字段和含义，并提供相同四列编辑习惯；HP下方依附、PP可移动等原先仅手动存在的字段也保留在导入数据。 |
| 原字体与文字 | 优先沿用原FZJZJW字体与字号，配置字体失败用有效模板后备；文字0无字、1当前值、2百分比、3当前/最大+百分比、4百分比+当前/最大；明确水平/垂直对齐，大字号小条不裁字。 |
| 三向填充 | LEFT、CENTER、RIGHT均保留，包括相应材质裁切。 |
| 材质与边框 | 35种原材质逐字节复制到pfUI自己的目录，前5为BLP、其余TGA；自定义边框也复制。支持材质0不显示填充及边框0无边框，实际边框范围为0–4。 |
| 背景 | 保留开关、颜色和透明度。 |
| Shift拖动 | 保留Shift+左键拖动及锁定；位置/缩放存入自己的配置，依附解除后恢复可拖动；不会改动连击点、距离、仇恨或原资源条位置。 |
| 依附关系 | erb_hp/erb_pp自动对应新内置条；外部框名称继续使用。缺失、自指和循环依附安全回落到自身位置并提示。 |
| 显隐与渐变 | 保留隐藏总开关、满值隐藏、空怒气隐藏、战斗相关组合、分别设置淡入淡出时间；修正隐藏条被事件重新显示、淡入淡出时间反用及中途反向问题。 |
| 资源颜色 | 默认使用统一资源配色，方案在“独立资源条”设置页选择；现默认沿用角色原ERB蓝/红/黄，头像实际配色为可选项。原ERB自定义资源颜色仍保存在副本，关闭“使用统一资源配色”可单独编辑兼容条颜色。 |
| /erb | 旧版存在且不试用时仍打开旧面板；试用中打开内置面板；没有独立版时也能打开内置设置，打开设置不会自动启用条。 |
| 设置保存 | 所有字段先验证再整体保存；非法颜色/数字不会部分覆盖配置；颜色不执行Lua输入；重置只填草稿，点击保存才应用；颜色拾取支持现值、透明度及取消恢复。 |
| 禁用与回退 | 试用中暂停旧HP/PP及旧加载框的事件/逐帧脚本，防止两套同时更新；结束试用立即刷新旧条当前数值，再恢复原脚本、显隐、透明度、淡出状态和命令。独立插件仍保持启用，便于游戏验收前随时退回。 |

生命条的渐变仍以生命比例为准。旧“仅战斗+满值隐藏”的组合习惯保留：战斗中显示，脱战未满时继续显示到恢复满值；不是把该组合强行改成一脱战立刻隐藏。

## 使用和验收步骤

1. 保持 ExtraResourceBars 启用，`/reload`，进入原来使用这些条的角色。
2. 打开 `/pfui` → **头像框架 → 生命与资源条**，先点“首次导入现用设置”。导入当前角色，不批量覆盖其他角色。
3. 勾选“启用内置版本（试用）”。旧版两条会暂时让位，内置条按导入位置和设置显示；`/erb` 仍可编辑。若同时开着此前的 pfUI 独立能量条，其设置保持不动，可在兼容面板隐藏PP只使用生命条。
4. 核对位置/缩放、Shift拖动与解除依附，生命受伤和恢复、形态/最大资源变化、满值/空怒/进出战斗、两种淡入淡出、文字格式、材质和背景。数字大于条高、字体文件失败的路径已有离线检查，实际字体观感仍须游戏确认。
5. 点击“结束试用，还原独立版”验证可恢复；需要时重新开启试用，内置编辑结果保留。换角色时首次独立导入该角色设置。
6. **只有用户确认上述行为符合原习惯后，才执行正式停用独立版。** 本轮没有自动完成此步；离线测试通过不视为游戏验收。停用后保留内置配置和原文件作为回退，不需要再依赖旧材质目录。

原先手工 `/run ERB_options...` 的命令仍作用于旧版数据；内置试用期间应使用 `/erb` 面板调整，不将原全局表重定向成新表，以保留安全回退。
