# TurtleSeamlessMap 0.3.0：连续大陆图集与视口加载

日期：2026-10-24。实施依据为 [连续大陆图集方案](TurtleSeamlessMap-连续大陆图集可行性-20261024.md) 及用户随后明确同意开始重构。新增地图在忽略的独立候选目录生成和检查，不覆盖原提取证据；没有引入第三方地图、修改 MPQ、其他插件或保存设置。

## 实际改变

原版本按鼠标区域叠一张细图，其余位置回落到粗大陆页。0.3.0 改为离线连续大陆图集，原有 53 个室外区域全部参与，两大陆及新增岛屿共用原 DBC 地理基准。世界/区域美术分离已取消；所有缩放级别来自同一份大陆原稿，不再在近景下显露旧大陆粗轮廓。

节点策略保持独立：鼠标区域仍决定任务、飞行点、旅店等节点的遍历和详情门槛，世界总览不扫描整大陆节点。区域几何记录、MapToWorld 和旧标记迁移不变；重新制作的 FocusData 负责选区，不用贴片边界当区域边界。

新增 AtlasData.lua 与 Atlas.lua，TOC 按依赖加载。Geometry.lua 将旧页的 tiles/backing 清空，仅保留其地理信息；七城读取新轮廓贴图。Core.lua 对世界和大陆调用网格绘制，普通室外页不再单独叠加；原世界总览锁定、M 定位、原图回退及兼容回调保留。

MapData.lua 同步去掉失效的旧页贴片目录，只保留原地理记录。用 Lua 5.1 分别载入提交前后数据，逐值核对 63 项的 ID/名称/归属/边界和两套布局变换，数值完全相等；此项不只比较近似坐标。

## 源图与轮廓制作

新 Tools/build_turtle_map_atlas.py 从本机未裁切 PNG 和覆盖层重新制作，在独立 v4-candidate 目录输出。逐区标注 53 个外缘，探索 alpha 只在标注外缘附近补充，不能把整页探索图当完整轮廓；同时分别生成地理/绘画核心、外围描绘及鼠标命中。源页图框逐渐剔除，边界颜色向共同纸张色作有限调整，内部保留原配色。

提尔之手对应 ScarletEnclave 502，无探索覆盖，明确采用专用轮廓并离线连接父区；不再走“无覆盖层则整页不透明”的方框后备。代表片区覆盖安戈洛—希利苏斯—塔纳利斯、湿地及提尔之手/东瘟疫；第一轮预览发现的原页框、装饰指南针和误连岛屿问题已在生成器中调整。海峡不能用宽形态闭合填平，闭合范围已限制到约一个世界单位。

区域核心没有为了匹配旧世界图而位移、旋转或变形；纸张边缘的美术过渡不修改玩家/任务坐标。制作画布网格取整造成的亚像素误差须与地理记录保持的数值契约分别理解，不把离线投影校验当所有实际地标的游戏测绘。

## 本机小地图核查与空白陆地

按客户端补丁顺序只读加载小地图索引，去重的 Azeroth 室外路径 736 条、Kalimdor 1,019 条，总计 1,755 张全部读取和解码，均为 256×256，解码失败零。WDT 地形标志分别 741、1,088；其中未在该索引中对应到的格子分别 26、73。索引还有不在 WDT 标志集合中的格子，所以不能直接用总数相减当缺口数。清单保存了具体格子、内容指纹及来源，不将未对应格子宣称为完整读取。

小地图下采样后按颜色估算海陆，并限制在保留地图附近的范围；它不是服务器精确海岸，也不是新的手绘图。它辅助保留原图未描绘的陆地轮廓，避免只能拿旧大陆粗图补底。没有直接将卫星地形贴进羊皮纸地图。

手绘图未覆盖的陆地带采用本机原图纸纹和很淡的山线作装饰。该部分属于补绘，不代表新增道路、城镇或可玩地形。颜色估算、标注轮廓、原区域边界比例及未绘制山带仍可能需要逐区人工修整；本版完成统一图集架构及第一次全域拼接，未宣称完成全部大陆的逐像素手工重绘。

## 世界背景与主城

背景以原 World.png 为底，保留漩涡、船只、中央原有岛屿、海纹、纸张和边框。移除旧大陆与近岸光晕，缺口使用原图海面纸纹延展；远景陆地由同一套新大陆图集缩小。canvas 不再用 SeaPaper 固定屏幕平铺，近景继续显示同一原风格世界背景。原画有限像素在深度放大时仍会变软，不把插值称为新增高清细节。

七城重新输出原密度的 1002×668 轮廓贴图，各 12 个贴片，原坐标不变。取消 0.2.2 烘焙到城市外围的模糊父区，直接透出连续大陆美术；地下城市继续保留近景独立层。城市门槛、轮廓命中、港口文字及页角排除的回归覆盖保留。

## 分级、接缝与运行时预算

大陆图集为每世界单位 1、2、4、8、16 像素五级，源于同一份高层原稿；最高层尺寸为卡利姆多 6,080×9,408、东部王国 5,280×8,080。BLP2/DXT3 的 256×256 贴片中间 254×254 为有效格，周围一像素复制相邻图集像素；部分末格使用实际 UV，不拉伸到整格。

运行时直接计算视口相交行列，只查这些格子的稀疏索引，按屏幕比例选择分辨率。背景及两大陆各最多 256 个纹理槽位，固定场景 frame 层级；槽位只在资源变化时改绑，同场景贴片互不重叠。清除视口外引用，不为每个访问过的文件永久创建控件。城市数量有限，仍使用固定资源归属。纹理载入失败时整场景回退到低一级，避免缺一个格就留下洞。

鼠标单独移区不重排背景/大陆纹理；滚轮立即更新美术与已有图标，节点刷新继续分开合并。没有使用现代地图 API、运行时遮罩、网格变形或渲染目标。Lua 能限制 live 纹理引用，但不能保证驱动缓存即时释放；没有以磁盘大小推算实测显存，也没有游戏帧率结论。

## 资源、部署与回退

新候选部署前校验全部文件名、SHA-256 和贴图解码。仅替换本插件旧 v2/v3/SeaPaper 派生资源，原始 173 图页、3,551 张 BLP、完整 PNG 和历史报告保持不变。文件与指纹见 [0.3.0 资源清单](TurtleSeamlessMap-0.3.0资源-20261024.json)。候选预览和小地图参照保留在本地忽略目录，不上传截图或原档案。

旧 v2/v3 工具作为历史制作依据保留，不再用于覆盖现用资源。新入口先生成，人工检查候选后通过 --deploy-reviewed 明确部署。需要回退时使用 Git 中前版派生美术和代码，原客户端地图入口始终保留。新资源应完整退出并重启客户端后验收，无需清空插件保存数据。

## 检查结果

新图集共 1,270 张派生 BLP，83,418,680 字节（约 79.6 MiB），其中大陆各级 1,138 张、背景 48 张、城市 84 张。移除旧 865 张派生贴片；这只是磁盘资源统计，不是内存或显存测量。

33 组 Lua 5.1/严格 1.12 模拟与资源检查通过：1,270 张贴片完整解码及指纹、五级同源轮廓、相邻贴片 gutter、53 区中心覆盖及原投影、60 区可选、纹理池上限及离屏引用清除、首次加载失败退到低一级并恢复、鼠标单区节点/禁止遍历非焦点表、立即缩放与不变底图复用、纹理反序合成、城市门槛及原坐标、首次原入口拒用残留页和有限补定位、Atlas/pfQuest 实际回调、旧标记迁移及字体初始化失败后备。

测试最初发现两个检查约定需修正：离线 JSON 保留完整双精度，历史 Lua 写入 10 位有效数字，比较界限调整为 0.000001 世界单位（小于 0.000016 图集像素）；载入失败应在首次 SetTexture 前注入，而不是让已成功缓存的纹理凭空失败。修正后完整 33 组通过，没有通过修改实际坐标来消除数值差异。

已查看原图接触表、两大陆整图、原背景世界合成，以及按实际 Lua 绘制状态合成的安戈洛、湿地、提尔之手、暴风城近景。预览不是游戏截图。Python 编译与差异空白检查通过；维护页/索引/链接和上传审计按本次提交流程执行。未进行新游戏加载、性能采样或逐地标测绘，全部实际海岸、城市出入口及用户关注边界仍待游戏验收。
