# TurtleSeamlessMap 0.2.0 实现与检查

日期：2026-10-24。对应用户六项反馈及 [0.2.0 方案](TurtleSeamlessMap-0.2.0优化方案-20261024.md)。本次为代码、派生资源和离线检查，不是游戏验收。

## 实际范围

- 运行时保留 53 个室外区域、7 座主城、2 个大陆及世界，共 63 项数据；列表只列 60 个室外/城市图页。
- 移除 110 个运行时记录：96 个实例/楼层/无坐标备用图页，以及 14 个 GM、入口、洞穴和通道放大图。完整保留清单、排除原因及边界见 [0.2.0 资源清单](TurtleSeamlessMap-0.2.0资源-20261024.json)。野外入口图标与 Atlas 回调继续保留。
- 原提取的 173 图页、3,551 个原始 BLP、完整无损预览和首版提取报告保持不变。53 个室外区域包含客户端已提取的新增区域；没有用正式服地图替换乌龟服地理。
- 派生材质由 912 个改为 792 个 BLP2/DXT3，52,021,728 字节（约 49.6 MiB）；这是资源文件大小，不是实测显存/内存。

## 统一世界与层级

`MapData.lua` 写入安装客户端 `WorldMapContinent.dbc` 的大陆偏移和比例；`Geometry.lua` 将两大陆的游戏坐标投影到同一个 1002×668 世界画布，替代首版东大陆固定加 42,000 的两套原点。

世界呈现采用 64 个 ADT 宽、1002:668 比例。大陆变换为 `worldX = centerX - gameY * scale`、`worldY = centerY - gameX * scale`，参数随资源清单保存；源表字段可对照 [WoWDBDefs 原始定义](https://github.com/wowdev/WoWDBDefs/blob/master/definitions/WorldMapContinent.dbd)。64 ADT 呈现是本版采用的布局约定，不声称客户端暴露了同名投影 API；大陆底图与世界美术的微小偏差仍需逐区视觉校准。

世界、两大陆按钮、区域定位、城市定位和第三方跳转始终操作同一画布。大陆按钮按保留室外区域的边界定位，避开原大陆图宽阔的装饰页边。移除独立完整图页和副本场景分支；原地图回退入口保留。缩放仍围绕鼠标支点，不在平移/缩放期间切换客户端全局地图。

区域详情采用视口相对尺度。区域贴图、城市层和适配器共同读取 `UpdateVisibility()` 的状态；`CanShowMapPins()` 必须在枚举区域节点之前检查。pfQuest 的隐藏区域只读区域索引，不访问其节点表；ModernMapMarkers 使用同样的门槛。个人标记及玩家定位可保留远景显示。此规则不自动控制尚未接入的第三方提供方。

七座主城同时检查缩放、视口相交及视野中心或可见鼠标缩放焦点的位置；进入/退出阈值分别为相对覆盖 0.72/0.58，按比例渐变，城市节点等到详细层可读时才出现。父区域正常定位时详细城市层不出现，保留区域图自带的城市轮廓。铁炉堡、幽暗城也使用此规则；不是把地下城市当作普通地表区域持续覆盖。

## 海陆补底与保留内容

- 远景使用本客户端世界美术，包含两大陆、海洋和大漩涡。放大后淡出总图文字/边框，转入使用本客户端海面颜色的轻微程序纹理；不重复放大原图文字和海浪。
- 使用各区探索覆盖层构造陆地覆盖范围，扩展并填充狭窄/封闭间隙；补底取自本客户端大陆美术，按陆地颜色过滤掉大部分海面线条，再与区域边缘过渡。
- 这是自动补底，不是新绘制的高精度山地美术。原素材分辨率、未绘制山地、区域色差、海岸以及地图边界仍需逐区游戏检查；不宣称已经消除全部接缝。
- OpenMap 只参考分层、补底及门槛思路；没有引入其正式服地理、现代客户端 API 或素材文件。原 MIT 参考许可继续保留，客户端地图美术权利不变。

## 保存数据迁移

`layoutVersion=2` 表示新版坐标。升级时保存完整 `layoutV1Backup`，将可确定所属大陆的旧世界标记、保留图页的旧独立标记及视图换算到新画布。移除图页或不能可靠定位的标记进入 `unplacedNotes` 并提示；不会丢失或猜测位置。迁移只执行一次，首次新装不会生成无用旧备份。本次未修改磁盘上的 WTF 或账号设置；迁移在插件正常载入后执行。

## 已执行检查

`Tools/tests/test_turtle_seamless_map.py` 使用 Lua 5.1 和严格 1.12 界面模拟。18 组检查通过：

- 原 173 图页完整性、3,551 个原始 BLP 指纹及预览尺寸；新版 63 项数据/60 个列表项与排除列表；792 个派生材质存在、可解码且尺寸正确。
- 坐标往返、邻区投影、鼠标支点缩放、裁剪、全部保留图页可定位、两大陆同画布和原图回退。
- 隐藏节点表一旦被枚举就直接失败：世界远景及离屏区域不枚举，艾尔文近景枚举该区；缩回远景再次停止枚举。
- 七城在父区域视图隐藏，在城市近景启用，移开视野隐藏；进入/退出缓冲，以及画面边缘城市的鼠标支点缩放。
- 旧世界/城市标记、未知与移除图页标记、视图迁移、完整备份、重复载入不再迁移。
- ModernMapMarkers 的筛选、阵营与 Atlas；实际 Modern 地区数据解析；pfQuest 节点表完整性及实际 `NodeClick` 的路线回调。
- 缺少可选插件时独立运行；200 次缩放/平移不切换全局地图或重建任务缓存。
- 字体设置失败时使用内置 FontObject；未初始化字体的 `SetText` 在模拟器中确实失败。

从 Lua 实际绘图命令生成并人工查看世界、大陆、艾尔文和暴风城离线预览；预览位于忽略的 staging，不是游戏截图。维护索引、记录覆盖、链接及上传历史审计另按项目流程执行。
