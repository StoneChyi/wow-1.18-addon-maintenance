# TurtleSeamlessMap 0.2.1：固定总览、当前位置与鼠标区域刷新

日期：2026-10-24。用户在 0.2.0 后反馈完整世界未铺满且可拖出空白、M 打开未优先显示当前位置、缩放刷新慢并出现大块粗略地图；随后要求只显示鼠标指向区域的细图。本版一起处理这四项。截图只作为用户反馈依据，不上传截图或游戏/账号数据。

## 已实现行为

- 地图画布保持原始世界图的 3:2 比例，并按可用屏幕调整窗口尺寸。完整总览正好铺满画布，地理不拉伸、不裁掉区域；禁止继续缩小和拖出空白。放大后允许拖动，但相机限制在世界边界内。
- 每次按 M 或普通 `/tsm` 打开，调用一次客户端的当前区域定位，再显示该区和有效玩家位置。取不到有效区域时回到世界总览；玩家坐标为零时不制造玩家图标。显式 `/tsm world`、区域列表和第三方指定区域跳转继续保留目的地，原地图回退保留。
- 达到比例门槛后，只允许鼠标当前指向的一块地图显示细节及地图/任务节点。主城满足近景门槛时优先，父区域不同时绘制详细层；邻区保留大陆补底。鼠标移出地图或操作列表/筛选菜单时保留最近指向的区域。总览没有区域细图和全大陆任务节点。
- 从既有 792 张派生贴片的透明度生成 60 个 48×32 命中表，随新增 `FocusData.lua` 载入；用于排除区域矩形里的透明海面和页边。新增 `Tools/build_turtle_map_focus.py` 可重建，不修改贴图、MPQ、首版提取清单或 0.2.0 资源证据。这是美术覆盖近似，细小边界仍需游戏校准。

## 刷新与层级修复

检查到 0.2.0 把世界、陆地补底、区域和城市贴图放在同一 frame 的 ARTWORK 层，并按当前可见顺序改绑一个全局纹理池。这使粗略补底与细图的前后关系依赖同层对象排序；用户截图与该风险吻合，但没有在真实客户端中证明这是截图的唯一根因。

本版为每张地图固定独立 frame 和绘制等级：世界 < 大陆补底 < 室外区域 < 城市 < 标记。海面放在世界 frame 的 BACKGROUND 层，世界原图在 ARTWORK 层。每个纹理固定归属地图和资源路径，首次使用时才载入，后续缩放/平移不反复改绑，也不在打开地图时预载全大陆细图。未使用纹理只在从可见变为隐藏时隐藏。

缩放输入直接完成 `RenderArt`，不再等 0.03 秒节流；拖动和鼠标跨区在下一次 OnUpdate 更新。已有标记立即按新视图重排，失去详情资格的区域标记立即隐藏。节点提供方独立刷新：停止操作约 0.08 秒后更新，持续操作时每约 0.35 秒更新；静止时不重绘未变化的地图。只移动鼠标跨区时，世界/大陆底图保持原几何与资源绑定，只切换细图。

ModernMapMarkers、Atlas、pfQuest 原有文件不修改；适配器为图标补充所属区域 ID，以便节点重新遍历前也能及时隐藏旧区域图标。外部 AddPin 调用保留兼容，可选追加 mapID。

## 检查结果

`Tools/tests/test_turtle_seamless_map.py`：25 组 Lua 5.1、严格 1.12 界面模拟及资源检查通过。新增/扩充检查包括：

- 四种屏幕尺寸下窗口范围、原图比例、完整世界四边与画布四边重合；总览不能拖动或继续缩小；放大后边界约束。
- 多次 M 打开在浏览过远方区域后仍定位玩家；不同当前区域、零玩家坐标、未知区域及显式世界/第三方跳转。
- 60 个区域和城市均存在可由鼠标选中的有效绘图范围；透明页边不能命中；同时只显示一个区域细图；非焦点节点表一旦被枚举即失败。
- 鼠标移区无需滚轮即可切换，鼠标在同区内移动不重绘；只切换区域时，世界/大陆纹理的位置设置次数保持不变。
- 固定地图 frame 等级、纹理资源归属、海面/世界原图 draw layer、旧纹理隐藏、暖缓存不重复 SetTexture/创建对象。
- 连续 40 次滚轮输入在处理完成时已更新地图，未调用节点提供方；操作暂停后合并刷新，静止轮询不重绘地图，缩回总览立即隐藏旧区域标记。
- 根据 frame 等级和 draw layer 合成，而不是按绘图调用顺序叠图；把同层纹理顺序反转，合成结果逐字节相同。世界、艾尔文和暴风城离线预览已查看，仍不是游戏截图。
- 原有完整提取与指纹、792 张贴图解码、城市门槛、ModernMapMarkers/Atlas、实际 pfQuest 点击函数、保存数据迁移、字体设置失败后备等检查继续通过。

本次地图美术数量和内容保持 0.2.0，未新增副本。维护索引、覆盖、链接、Git 差异和上传历史另按项目流程检查。
