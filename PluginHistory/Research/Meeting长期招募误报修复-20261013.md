# Meeting：长期固定团广告误报修复

日期：2026-10-13。依据：用户游戏截图中的 NAXX“双许+4团收人、需要固定职业、活动时间7.20-11点”广告被列为副本招募。只将必要措辞匿名转录为测试样本，没有将截图或账号设置加入仓库。

## 原因与复现

原识别器已经要求存在招募意图，但“收人”能通过“收＋人”的职责判断，尚未进一步区分长期招固定成员和当前活动临时组人。已有公会广告排除词仅针对相邻的“公会招人”等短语，无法覆盖截图中用团名、固定活动时间和职业要求表达的长期广告。

先在修复前加入截图同类文本的拒绝预期，真实 Lua 执行返回 `NAXX / recruit` 并使回归失败；修复后该样本返回 `ignore / long_term_recruitment`。

## 新增规则

在去掉链接和颜色后、分句前，对完整消息增加长期招募组合判断：

- 明确的“长期招募／长期收人／常年招募／长期缺人”等信号。
- 招成员信号（收人、招人、招募、招收、纳新等）结合公会／固定团身份。
- 招成员信号结合“活动时间／开荒时间／固定时间”。
- “每周／每晚／每星期／长期／常年”等周期信号结合收人或职业需求；多个不同星期的活动安排结合成员需求。
- 补充英文 guild、recruiting、recruitment、weekly 组合。

这样可以覆盖招募词和固定时间被逗号／句号隔开的广告，不要求广告一定出现“公会”两个字，也不把任意时间或任意公会名设为全局屏蔽词。

## 当前临时组人的保留条件

出现明确当前缺口时，保留对应副本的当前组人段，例如现缺／现在缺／当前缺、临时缺／临时补位、有效 `39=1` 人数缺口、LF2M。

当整条消息同时包含长期广告和当前补位，只接受有当前缺口依据的副本段。单个副本的紧邻下一句是明确临时补位时可以承接；不把另一副本的补位意图套到所有长期招募副本上。

例如：

| 文本 | 结果 |
| --- | --- |
| NAXX双许+4团收人，需要法师，活动时间7.20-11点 | 忽略长期广告 |
| NAXX固定团每周招募治疗 | 忽略长期广告 |
| NAXX今晚7.20-11点开组来2奶 | 保留临时组人 |
| NAXX今晚活动时间7.20-11点 开组来2奶 | 保留临时组人，时间本身不作为长期广告依据 |
| NAXX固定团活动时间20-23收人，今晚临时缺1奶 | 保留当前 NAXX 补位 |
| 公会招募固定成员NAXX，BWL现缺1奶 | 仅保留 BWL |
| 物品链接名称包含现缺1奶39=1，正文是NAXX固定团每周收人 | 链接不作为临时缺口依据，忽略广告 |

过滤掉的消息不覆盖、刷新或关闭该玩家已有的临时招募。不新增菜单、持久化设置、计时器、扫描或网络请求。结构化 LFT 的明确发布继续走原路径，本次针对世界／硬核等聊天文本的自动识别。
