# TurtleSeamlessMap 0.2.2：首次定位、主城轮廓与海面

日期：2026-10-24。处理用户对 0.2.1 的三项反馈：第一次开图跳到塔纳利斯、主城整页方形覆盖、放大后海面为灰色。两张用户截图仅作本地反馈依据，不纳入仓库；本次没有操作账号设置或修改其他插件。

## 定位问题依据与修复

0.2.1 的 `Toggle()` 会定位当前区域，但 `WorldMapFrame` 的 OnShow 重定向分支直接把 `GetMapInfo()` 返回的浏览页当成目的地。pfUI 等原图入口可以直接显示原窗口，绕过本插件 Toggle；而 GetMapInfo 只代表当前选择的地图，不保证是玩家所在区。若最后选择的是 Tanaris，就会跳到塔纳利斯。

在独立 Lua 5.1 模拟环境中读取 Git 提交 `5702a0b` 的原代码，保持玩家真实区域为艾尔文、残留浏览页为 Tanaris，直接打开原窗口：旧代码选择 161（Tanaris）；修复代码选择 30（Elwynn）。这证明存在一条与用户反馈吻合的可复现路径，不证明已在游戏里追踪到用户当次的具体调用插件。

修复将普通原窗口入口也统一为当前位置定位；明确的 ModernMapMarkers/pfQuest 跳转仍保留指定目的地。调用当前区域同步后，核对真实区域与选中地图；不一致时先定位正确区域中心，不读取/套用旧页的玩家坐标。若地图或玩家坐标尚未就绪，最多在后续 0.1 秒间隔补定位两次；一旦成功或耗尽次数就停止，用户缩放、拖动、改选区域或关闭也立即取消。平移与缩放仍不持续切换客户端全局地图。

## 主城可行显示方案与实际实现

对照用户提供 OpenMap 本地 `OpenMap/Map/Stitch.lua` 的城市独立层、轮廓渐隐、背景海陆分层，以及城市淡出空白周边的思路。本次没有移植正式服地图、C_Map、运行时纹理遮罩接口或 OpenMap 的正式服轮廓文件。

七城分别依据本客户端原始美术标注轮廓，去掉页框、角落徽记/指南针和标题饰带，保留街区、道路、码头及关键区域标注。暴风城港口的文字在城市主体轮廓以外，单独保留。轮廓外渐隐，城市周围取本客户端室外图的地形颜色生成柔和过渡；先柔化邻区原有的城市立绘和大标题，避免把它们放大叠在街道旁边。

外围过渡离线合成到同一张城市图集，不增加运行时的相邻区域详细层或任务节点。每座城市图集从 1002×668 扩展到 1504×1004，原城市图置于偏移 (251,168)，保留原城市像素密度。`artRect` 只扩展美术覆盖，不改变原 DBC rect、MapToWorld、玩家和任务坐标。七城各 24 个贴片，实际仍按视口裁剪及单鼠标区域规则绘制。

新增 `PresentationData.lua` 和 `Tools/build_turtle_map_presentation.py`。命中表同步使用城市新轮廓，装饰角落不再算城市范围。未引入副本，完整世界仍固定铺满。

这是现有 1.12 接口下的离线遮罩/过渡方案，不声称完全消除所有接缝或实现几何上完美融合。主城图本来是示意图，外围是柔和地形颜色而非新增高精度地形；原始完整图页及原地图回退仍保留，逐城边界和标注需游戏复核。

## 海面

取消原来 12 张随世界缩放的近乎平色海面贴片。新增一张 256×256 的 BLP2/DXT3：青绿色纸纹、轻微明暗变化和细波线。采用实际 1.12 已使用的 Frame backdrop 原生平铺，tileSize=128；图案细度不随地图放大变成巨大色块，也不需要逐帧在 Lua 铺大量海面纹理。完整世界远景仍显示客户端原图海洋与漩涡，海岸保留区域原绘图。

波线/纸纹由程序生成，不代表新增岛屿或地理。海面配色和海岸交接仍按游戏视觉效果验收。
