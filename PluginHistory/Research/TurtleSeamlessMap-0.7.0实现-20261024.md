# TurtleSeamlessMap 0.7.0：可靠开图、完整东部、稳定城市与边界延展

日期：2026-10-24。起始工作区和暂存区干净，基线 44fd3fde84d56c8346ed87ac886a49caa1bf00aa。用户反馈八项问题：登录自动开图并误跳塔纳利斯、东部王国缺失、地表城市随鼠标切换、方块边界、安戈洛南侧填充不均、多个指定接缝、局部低清、暴风城运河被画成道路；明确允许取消鼠标单区细节限制。

## 登录与定位

原窗口 OnShow 原来会无条件打开自定义窗口，且把 ignoreMapEvent 查询保护误作明确导航凭证。初始化、地图数据查询等后台操作因此可能露出保存的旧视野，或被误导向残留页。现在分别保护安装、定位和查询过程；原窗口 Show 在进入 OnShow 前捕获真实鼠标开图上下文，无鼠标操作的后台 Show、按钮更新、受保护的嵌套 Toggle 都不弹图。抑制原窗口关闭时的地图事件对自定义窗口的影响。M、/tsm 以及普通鼠标开图请求当前位置，pfQuest／ModernMapMarkers 的明确跳转通过已有适配器指定目标。

GetRealZoneText 存在但尚未返回真实区名时，不能用旧的显示区／子区名后备。选中页与真实区域不一致时仍不读取其玩家坐标，保留有限重试及用户操作取消。安装可以保留上次视野数据，但不会自行显示。直接从后台调用 WorldMapFrame:Show 不再视为开图意图；自定义脚本应使用 ToggleWorldMap 或 /tsm。原地图按钮仍可回退原窗口。

## 东部王国缺失的根因

0.6 最后一次资源处理中，经 JSON 重读的东部贴片表使用文字键，卡利姆多新生成表则使用数字键。Lua 按数字编号查表，因而东部文件齐全却不绘制。复现中东部场景的可见纹理槽为零，修正键类型后同视野恢复 12 个槽。

共享 Lua 写出器统一恢复规范的数字键，并在最终生成的 Lua 中检查全部大陆／城市层与物理文件对应。新增回归实际绘制两大陆的每个缩放层，不能只凭 Python／JSON 清单完整或贴图可解码推断游戏层可见。原 MapData、地图范围、区域投影和标记坐标不改。

## 城市与节点

真实地形的城市显示条件改为视野和缩放，脱离鼠标目标。五座地表城市用同一近景图像融入大陆各级图集，近景专层增加像素；铁炉堡、幽暗城保留原生室内专层。鼠标仅改变当前名称／检查目标，复用所有地形场景的贴片，不重绑城市图像。城市细节关闭时停用额外专层，地表城市仍属于基础大陆。

真实地形的区域节点资格也按倍率与视口决定，允许多个可见区域；世界总览不枚举区域节点。坐标在画面外时先跳过元数据，图钉满 900 后停止遍历。原任务提示和点击、分类／阵营筛选、Atlas、玩家及个人标记、设置迁移保留。手绘模式保留旧节点选择逻辑。

## 地形边缘与缺源地貌

两大陆分别在 551、406 个涉及柔化／修补的 ADT 上重新生成材料细节；范围重叠，不将多个阶段像素数当成独立区域面积。使用每 ADT 768 像素、实际 MCAL 材质透明权重与顶点高度，纹理相位沿世界坐标连续，颜色场和羽化跨块延伸。道路按实际覆盖形状保护，不再因一个小格提到道路材质就整格跳过。基础地形原海岸 alpha 保留。

核对到安戈洛南侧部分客户端高度本来是完全平坦的占位面，增加采样精度仍得到土色块。六组重点范围另做岩土延展，覆盖安戈洛南侧、希利苏斯西侧、厄运周围、菲拉斯—千针石林、灰谷—海加尔、冬泉谷—月光林地及相邻空白带。以经目视检查、不含道路／建筑／POI 的原生岩石小样，做确定性重叠匹配和最小误差接缝合成；世界坐标采样、可信邻域色彩和渐变遮罩融合。没有沿用早期候选中过强的拉伸或镜像图案。此处属于装饰性地貌纹理，不据此生成可通行区域、道路、建筑或任务点，也不称为新的真实地形测绘。

旧的手工填充矩形及其未分类边缘退役，防止新纹理下面仍露出原直线。安其拉衔接带和南庭院在全部柔化之后再精确还原，避免重采样渗入最外侧像素。实际模型、城市框、道路和水面有保护。图集最高密度仍为 32；保留地标，普通室外小建筑仍受原生素材精度限制，没有声称整个世界都重新建模。

## 厄运之槌外部与暴风城水面

厄运之槌只读取实际放置于卡利姆多 ADT 的 WMO／M2，36 个 WMO 与 365 个 M2 模型被读取，本次外景读取没有错误。按真正模型覆盖混入地形，羽化周围缺细节带，没有增加副本地图页。原地标、路径及地图投影保留。

暴风城原静态读取器漏掉 WMO 的 MLIQ 水面，露出运河底部材质。现在读取 22 组实际水网格、5,784 个水面三角形；验证尺寸、顶点数组、禁用格及绝对局部高度，用原波纹 alpha 表现静态水色。原有深度缓冲使桥梁保留在水上，不能把水色简单覆盖所有蓝色屋顶或桥面。

格式参考 [pywowlib 原始读取代码](https://github.com/wowdev/pywowlib/blob/master/file_formats/wmo_format_group.py)，并以本机源文件和实际静态绘制核对。只修复已确认的暴风城水面；没有假称支持所有地点／液体类型的完整客户端水面着色。原船模型结构与砖堆缺失后备继续记录，未改变游戏档案。

## 制作、部署与检查

新增 Tools/build_turtle_map_continuity.py，在独立 v8 候选制作、目视审查、打包与审计后部署。all 制作和审计但不自动部署；deploy 要求资源指纹、Lua 指纹及受保护像素检查。原始提取、历史报告和旧候选主图不改，模型／缓存及对比预览留在忽略目录。

69 组完整检查通过（Lua 5.1、严格 1.12 字体／界面模拟、源资源和实际 C# 静态绘制器，37.874 秒）。新增覆盖安装前已显示的原窗口、安装内 Show／Toggle、无鼠标上下文的按钮更新、保存塔纳利斯视野、空真实区名加陈旧显示区名、两大陆各层实际绘制、JSON→Lua 数字键、城市鼠标切换、多个可见区域节点与画面外元数据裁剪、真实水网格及桥梁遮挡、纹理合成可重复性／边缘和受保护像素。原定位、字体失败后备、任务回调、坐标及图集边缘／资源完整回归保留。

最终 6,024 张地形／城市贴片与写出的 Lua 数字编号一一对应，指纹和解码通过；全插件仍为 7,318 张、480,675,512 字节（约 458.4 MiB）。原 v7 大陆／暴风城资源被替换，其余城市、手绘、原版总览及海面保留。两大陆基础海岸 alpha 指纹一致，安其拉衔接带及南庭院最终主图像素与旧版完全一致。MapData 字节指纹不变。
