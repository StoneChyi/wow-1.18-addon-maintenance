# Cooline 共享技能冷却检索（2026-10-12）

## 检索范围和依据

用户报告使用圣盾术后圣佑术也显示一个计时；前版白名单只有十字军打击 / 神圣打击。本次扫描本机客户端九个职业的全部技能系条目，并查询乌龟服公开补丁与技能资料。客户端类别用于建立候选关系，不代表服务器必然使用相同机制；最终还须通过运行时计时一致性检查。

- 按 `patch-Z` 至 `patch-2` 的补丁优先级，再考虑 `patch.MPQ`、`dbc.MPQ`，只读查找三个 DBC 文件。不能用所有文件名的普通字典倒序选择补丁，因为那会错误地优先选中 `patch.MPQ`。提取文件只放在已忽略的 `PluginHistory/staging/cooline-shared-20261012`，不上传游戏数据。
- 实际选中 `patch-P.mpq` 的 `Spell.dbc`，27,917 条、173 个字段；SHA-256 为 `859ecfbebb9313b1a7d017ea686dca4b6b39a3751cdd06ca9e6485e91db41663`。
- `SkillLineAbility.dbc` 来自 `patch-9.mpq`，6,770 条；SHA-256 为 `833d1196df859482d9fe85cef48562c6b63731d3490833f750e98e2ff5518c5b`。`SkillLine.dbc` 同源，SHA-256 为 `a982ce23d52be7cac2a0ffb905f54a2ab35de65081dde113d897844accc0d23a`。
- 按九职业技能系分开检查所有非被动技能、非零 Category；同名等级合并。检查所有同职业多名称类别中至少一项冷却大于 2.5 秒的候选，不能先过滤每个成员的冷却，否则会漏掉自身时长为零的同类别成员。共得到 18 个候选类别组合，其中 16 组纳入运行时白名单、2 组排除；另加补丁资料确认的瞄准 / 奥术射击。
- 字段位置以 [CMaNGOS Classic 的 DBCStructure.h](https://github.com/cmangos/mangos-classic/blob/master/src/game/Server/DBCStructure.h) 核对：Category 为零起算字段 2，RecoveryTime 为 19，CategoryRecoveryTime 为 20，英文名为 120、中文名为 124。SkillLineAbility 的技能系为字段 1、spellId 为 2、classMask 为 4。同一 Category 会跨职业复用，不能把所有同类别法术放入一个组。

## 不合并的关系和资料限制

- **自律**：保护祝福与圣盾 / 圣佑的技能类别不同，自律是受术目标的限制，不把保护祝福、圣疗术加入无敌共享组。即便 API 返回相同开始、时长和结束，白名单外的技能仍独立计时。[乌龟服圣盾术资料](https://database.turtlecraft.gg/?spell=642) 同时列出 300 秒类别冷却及 60 秒受术限制。
- **诱导射击（Baited Shot）**：[乌龟服 2025-08-27 官方补丁](https://forum.turtlecraft.gg/viewtopic.php?t=21412) 明确记录取消与瞄准、奥术射击共享。本机三个 DBC 中没有该英文名，无法从当前提取数据补充核验；不因旧版玩家反馈添加该关系。瞄准 / 奥术这对沿用该补丁所描述的既有关系，但只在两者 API 返回完整一致计时时合并；不同的长短计时保留，不用较长者覆盖较短者。
- **牺牲之手 / 强效牺牲祝福**：本机类别 25，但前者没有冷却，后者只有 600 秒独立 RecoveryTime、没有 CategoryRecoveryTime。排除这组，不能仅凭同类别认定共享。
- **火焰冲击 / 魔火（Felfire）**：候选类别 19 的后者无自身或类别冷却，缺少可用于确认的共享关系，排除。
- **术士召唤**：本机地狱火与一个“召唤恶魔卫士”条目虽同属 731，但后者不在此次职业技能系有效候选中且基础类别冷却为零；末日仪式属于类别 0 的独立冷却。未把这几项强行并为一组。补丁中的恶魔之门、地狱火、末日仪式分别有自己的时间与变更，见 [1.17.2 官方职业改动](https://forum.turtlecraft.gg/viewtopic.php?t=15157)。
- **宠物、消耗品、饰品、专业制作**：本次目标为玩家技能条，原插件只扫描 `BOOKTYPE_SPELL`，不新增宠物监视，也不把药水或饰品混入技能共享表。物品保留独立命名空间与原扫描行为。
- **跨职业类别复用、公共冷却、学校封锁、同名等级**：跨职业不合并；不把所有时间相同的技能动态学成共享组。公共冷却沿用大于 2.5 秒的扫描过滤，同名等级沿用扫描归并；未增加学校封锁识别功能。

## 归并规则与实际验证

组内按开始、时长和结束三个量分别检查最大值与最小值之差，均须不超过 0.1 秒。只归并当前同步子集，最多形成多个独立子计时，不以一个不一致成员阻止其他成员归并。使用最晚结束时间，正常图标尺寸、无重复 `+数量`；悬停保留全部归并成员。

SuperWoW 玩家 CAST 成功事件仍优先选择实际使用技能的图标。旧轮次、START、FAIL、其他单位和施法尝试不决定代表；确认后本轮稳定，包括另一子集消失导致记录键变化时。无成功事件 / 无 SuperWoW / 中途重载采用表中回退。不同步时可拆分，同步后重新合并；提前清除不触发伪完成提示。

2026-10-12：`Tools/tests/test_cooline_layout.py` 的 **24 组 Lua 5.1 行为检查通过**，覆盖原有字体失败检查和 16 个新增组的中英文成功图标、独立/同步子集、无效与公共冷却、无 SuperWoW、圣盾报告、自律关联技能独立、两组陷阱计时、临近结束重新归键、容差、诱导射击排除及长冷却进入显示范围。

以上是本机数据检索、公开资料和模拟检查。没有连接服务器读取服务端技能表，也未在真实 1.12 客户端逐职业验收；不能声称已穷尽所有服务器隐藏共享机制或已完成实战验证。后续如有未收录关系，需要当前技能书冷却数据或明确版本资料后再补充。
