# pfUI 独立资源条整合与插件精简边界

实施日期：2026-10-30。用户单独授权第 1 项：独立显示层内置 pfUI，保留个人回能算法，不改连击点、距离与仇恨框布局；修复平滑、字体和隐藏，新条默认关闭。用户同时要求今后优先整合重叠功能、减少独立插件数量。

更新前提交：`2f0f5b25909cca8cf9b7734434dd6272eaaa9607`；回退标签：`before/pfui-resourcebar-20261030`。参考来源为 10 月 29 日包的 `pfUI/modules/energybar.lua`，没有整段覆盖或把个人版冒充原版祖先。

## 实际合入

| 内容 | 当前实现 |
|---|---|
| 模块与设置 | pfUI 内置 `energybar`，入口 `/pfui` → 头像框架 → 独立资源条；总开关默认关闭。没有新增独立插件目录。 |
| 资源显示 | 可显示当前资源，或仅在能量形态显示；当前值、当前/最大值、百分比；材质、类型颜色、固定宽高、文字和边框可配置；自动配色现默认沿用角色原ERB蓝/红/黄方案；也可显式选择头像实际配色。手动固定色仍可选，德鲁伊附条使用同方案法力色。 |
| 独立位置 | 默认屏幕底部水平居中，偏移 0/278；解锁后只拖动自身。保存的手动位置、缩放优先；默认偏移与手动位置重置采用原移动接口。 |
| 回能光点 | 仅读取个人 `energytick:EnergyProgress()`；有效相位为 0 时也正常显示。非能量形态、没有锚点、提供者缺失或报错均隐藏，不私自估计两秒周期。 |
| 个人算法 | 整段校准模型保留原字节；仅解耦模型状态与头像光点是否显示，并导出进度。自然增量筛选、样本中位数、漏拍归一化、敏捷/天赋及节律变化重锁保持。 |
| 平滑 | 约 0.15 秒追上新值，不再固定每秒 200 点。切换资源类型、上限变化或重新启用时立即重置，文字始终读真实值。 |
| 字体 | 主文字及基础法力文字均在首次写字前有有效字体模板，配置字体失败保留内置后备；锚定实际完整填充轨道，按实际字体和文字墨迹补偿垂直基线，去掉重复半像素阴影，保留单层描边。 |
| 德鲁伊基础法力 | 可选，默认关闭；变形时读取已有 GetUnitField 接口，按 0.1 秒采集，只显示玩家；接口缺失、字段报错或无有效上限时隐藏并允许后续恢复。没有升级 DLL。 |
| 自动隐藏 | 默认关闭；开启后按主资源无变化时间隐藏。“战斗中保持显示”开启时优先保持可见；关闭时战斗不再阻止隐藏。满资源默认保持可见，允许满资源隐藏后同样等待无变化延时。 |
| 淡出与开销 | 淡入淡出按真实 elapsed，约 0.2 秒；解锁预览保持可见。更新最多约 50 次/秒，稳定文字/宽度不重复写；总开关关闭不创建条或更新驱动，关闭已创建模块后卸载 OnUpdate。 |

## 缩减独立插件的后续顺序

1. **ExtraResourceBars**：资源显示与能量光点已内置 pfUI；生命条、填充方向、文字/隐藏规则与迁移已补齐兼容候选，下一步做可回退游戏试用，用户确认后再停用独立版。当前不宣称已经减少一个插件。
2. **pfUI 附属扩展**：优先评估 `pfUI-eliteoverlay`、`pfUI_ExtendedMerchant`。它们明确依赖 pfUI，适合进一步检查为内置可选模块，但素材路径、原配置与关闭行为尚未完整审核，本轮没有迁移或删除。
3. **职业核心、通信和大型工具**：保留现有个人核心；不能仅为了减少目录数机械合并 Cat/Cat2、治疗、威胁或属性统计插件。先证明功能等价和冲突边界，再单独实施。

减少加载条目与提升性能是两个判断：移动代码进 pfUI 不会自动减少事件和刷新工作。每次整合应同时消除重复采样、重复界面和多份配置入口，保留可关闭选项与原数据回退。

## 截图反馈修正（2026-10-30）

前两轮仅验证了文字框的对齐参数。截图证实实际字形仍偏低；中文force_region会把配置字体切到FZXHLJW，其数字墨迹中心与字体行框中心不同。现在使用实际GetFont，并以受控字体逐字符墨迹指标计算上/下补偿，锚定完整填充轨道。条高、内缩、位置和字号变化会重新计算；掉蓝不会让数字跟着动态填充宽度跑。保持已设置的字号，不以强制缩小字体掩盖位置问题。

默认资源色改为沿用角色原ERB资源颜色（内置副本优先，旧表次之），没有数据时使用清晰蓝/红/黄。头像方案仍可选，并优先读当前头像实际StatusBar颜色；若头像主题本来偏紫，选此方案也会保留该色。两类资源条均采用同一方案，不修改头像主题或角色原配置。

已增加真实TTF光栅检查，覆盖2080种文字/字体/字号/缩放组合；离线墨迹中心误差不超过1物理像素。仍须/reload后在游戏截图验收，未知字体路径/未知字符只做几何居中；同路径替换字体后需要重新生成指标。受控字体来源为仓库自带字体和固定的客户端字体名，不复制客户端字体到公开仓库。

维护时运行 `python Tools/generate_resourcebar_font_metrics.py --check` 核对指标；修改字体后重新生成并运行 `Tools/tests/test_resourcebar_font_render.py`。这些是离线工具，不在游戏内调用Pillow。具体检查与实施见[本次记录](../Plugins/pfUI.md#change-pfUI-20261030-07)。
