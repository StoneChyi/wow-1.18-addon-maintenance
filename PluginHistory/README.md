# 插件修改记录

这里只整理插件的修改历史；每个插件一份记录，按时间倒序查看。

## 一、没有变化的插件

[查看没有变化的插件](Plugins/README.md#一没有变化的插件)。指现有依据未确认本体迭代或修改；不是对“从未修改”或“官方原版”的保证。来源、作者或早期日期不明时保留原说明，不编造变化。

## 二、经过版本迭代或修改的插件

[查看经过版本迭代或修改的插件](Plugins/README.md#二经过版本迭代或修改的插件)。每页记录实际发生的更新、修改、反馈和回退，最新在前。

- **修改记录**：日期、改了什么、为什么改、实际检查结果及依据。
- **目前存在的问题**：确有未解决的问题才写；没有就不设这一节。
- **进一步优化方案**：已经提出且仍适用的方案才写；没有就不设这一节，不自动生成计划。

“待游戏验收”写在对应修改记录中，不自动列成当前故障。已解决、撤回或被替代的方案仍留在原时间记录里。

## 三、DLL 等其他组件

[查看 DLL 等其他组件记录](Runtime/README.md)。与插件分开，保留其版本、更新、检查和回退记录。
