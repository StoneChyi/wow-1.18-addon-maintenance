## 插件概况

- 插件：`EavesDrop`，1.12 战斗事件窗口；本次个人维护版 `1.4.3-pfUI`。
- 维护状态：**有维护记录**。2026-10-26 首次实施下述优化，不推断此前个人修改。

## 当前维护摘要

主窗、最高数值历史与独立设置面板统一为 pfUI 风格；背景不透明度可即时调整，战斗/历史窗口共用一项，设置面板独立一项。右键或 `/ed` 打开设置；`/ed enable`、`/ed disable` 控制监视，`/ed legacy` 保留旧设置入口。停用后重登默认隐藏窗口；滚动旧记录使用有限阅读副本，继续收集新事件、暂停淡出，点击底部提示恢复跟随。默认缓存 512 条，可调 128–2048；最高数值历史仍独立保存。自动隐藏状态下的空窗口不再被刷新重新显示。

统一旧事件订阅与玩家/宠物分发，补齐友方直接治疗等渠道，修正宠物输入输出统计。自动模式按 nampower 实际版本/接收情况接入五类增强记录，能力不足或注册失败按类别回退文字日志；百分比 DoT 单位不明时保守回退，旧吸取/汲取与击杀归属保留文字来源。没有更换 DLL、改写全局 CVar 或重置账号配置。已完成离线模拟与模块集成检查，**待游戏验收**。

## 逐次修改记录

<a id="change-EavesDrop-20261027-01"></a>

### 2026-10-27｜修复自动隐藏状态下空窗口被刷新重新显示

- 记录编号：`EavesDrop-20261027-01`
- 记录类型：修改
- 游戏验收：待游戏验收
- 对应提交：随本条记录一并提交（见本页 Git 历史）

- 修改原因：收尾复核实际复现无记录且 alpha 已为 0 时，OnUpdate 的条件分支反而执行 ShowFrame，使空窗口重新出现。
- 修改内容：自动隐藏仅根据当前有无可见记录决定隐藏/显示，不再以原 alpha 是否等于 1 决定进入哪个分支；阅读快照的暂停淡出规则保持有效。
- 涉及文件：`Interface/AddOns/EavesDrop/EavesDrop.lua`、[核心回归](../../Tools/tests/test_eavesdrop_core.py)、本页、[验收说明](../Research/EavesDrop优化-20261026.md)及生成索引。
- 关联功能：自动隐藏、淡出、启用初始化和新事件恢复显示。
- 检查结果：修复前离线复现空窗口更新后 alpha 从 0 变为 1；新增测试覆盖两次空刷新保持隐藏及新记录到来后恢复显示，28 项核心回归通过。增强与界面模块未修改，前条 40 组增强与 4 种界面环境检查仍为此前实际结果。
- 游戏验收与未确认：仍待实际游戏核对自动隐藏、空闲、新战斗和手动阅读时的表现；离线模拟不等同游戏验收。

<a id="change-EavesDrop-20261026-01"></a>

### 2026-10-26｜pfUI界面与透明度、稳定历史阅读、停用恢复及增强战斗记录适配

- 记录编号：`EavesDrop-20261026-01`
- 记录类型：修改
- 游戏验收：待游戏验收
- 对应提交：随本条记录一并提交（见本页 Git 历史）

- 修改原因：用户要求统一 pfUI 界面、排查战斗漏记、修复停用后重登仍显示和阅读旧记录被新事件推走，并补充背景透明度调节及参考正式服逻辑。
- 修改内容：主框默认隐藏，初始化和停用均隐藏主/历史窗；配置刷新及旧事件订阅幂等，设置在停用时仍可打开。旧日志统一经过玩家/宠物分发，补充友方治疗和宠物相关渠道，宠物选项不再注销玩家共用渠道；修正宠物治疗统计/颜色。新增有限历史阅读快照和新增提示，缓存淘汰后仍保留当前阅读副本；回到底部恢复实时，容量调整保留最新内容。新增 pfUI 风格分页设置、背景不透明度滑块、颜色/配置管理与原版设置后备；字体先初始化并保留内置字体后备。新增五类增强事件适配、GUID 身份过滤和来源去重，仅观察运行开关关闭以恢复文字来源；光环、环境和反伤继续使用文字，增强消息/图标明确传递至显示及最高值历史。
- 涉及文件：`EavesDrop.lua`、`EavesDrop.xml`、`EavesDropStats.lua`、`options.lua`、`EavesDrop.toc`，新增 `ui.lua`、`enhanced.lua`；三个 [核心](../../Tools/tests/test_eavesdrop_core.py)、[增强](../../Tools/tests/test_eavesdrop_enhanced.py)、[界面](../../Tools/tests/test_eavesdrop_ui.py) 回归脚本及本页/维护索引。详细行为及限制见[实施与验收说明](../Research/EavesDrop优化-20261026.md)。
- 关联功能：pfUI 可选皮肤/字体接口，Ace2 配置与启停，ParserLib 共用渠道，nampower 4.5+ 五类增强事件和现有 SuperWoW GUID 后备。无 pfUI、无 nampower 时保留独立界面和旧日志。
- 检查结果：Lua 5.1 下 27 项核心回归（含真实三模块集成）、40 组增强事件检查、4 种界面/字体环境检查通过；严格字体契约验证首次 SetText、空值、复用、隐藏页面及 SetFont 失败。文本编码/BOM/换行保留、TOC/XML/语法和维护文档检查另见报告。全部为离线模拟，未执行 DLL，未启动或控制游戏。
- 收尾复核（2026-10-27）：继续运行上述 27 项核心、40 组增强和 4 种界面环境检查，全部通过；仅提交本次 EavesDrop 代码、测试与维护说明。此时工作区另有 DLL/加载清单改动，未纳入本次维护。
- 游戏验收与未确认：需游戏核对全退出重进停用持久化、队友治疗/自疗/PvP/宠物/持续伤害/吸收抵抗、文字光环增删、中文新技能图标、战斗中历史阅读及界面布局。增强事件注册成功不保证服务器或当前 DLL 在每个场景都实际投递；旧日志无法恢复服务器未发送的数据。过量治疗原有基于即时血量的估算没有升级为真实精确过量字段。此前是否有个人修改仍无证据，不将整合包原功能写成本次新增。
