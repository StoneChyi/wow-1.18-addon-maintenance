### 2026-10-30｜统一传送图标与整条信息栏的文字对齐逻辑

- 记录编号：`diminfo-20261030-04`
- 记录类型：修改
- 游戏验收：待游戏验收
- 对应提交：随本条记录一并提交（见本页 Git 历史）

- 修改原因：用户反馈时光符文仍未对齐，要求重新审查代码并同时检查其他图标、传送文字与 DimInfo 其他文字的对齐。旧回归主要断言锚点参数，没有解析完整文字与按钮边界，不能覆盖实际布局差异。
- 修改内容：传送模块移出金币使用的整框锚定特例，改为与普通模块一样直接锚定文字；按钮以文字左上/右下边界确定点击范围，不再先设置固定 18 高度再把文字放入按钮。图标大小为实际字体大小 + 2，左侧留位为图标宽度 + 4，字体行框与可见字形的校正按实际字号缩放；字体变更后立即更新图标、点击范围与信息栏锚点，不等待物品刷新。显式移除 GameFontNormalSmall 模板可能继承的阴影、设置垂直居中，保留有效字体模板后备及 OUTLINE。四张线稿在导出前按几何范围居中、统一最大可见跨度，去除各图案不一致的内部留白；不新增独立的时光符文偏移常量。
- 涉及文件：`panel.lua`、`Modules/Teleport.lua`、`tests/teleport.lua`、`tools/render_teleport_icons.py`、`Media/Teleport/` 下 SVG/TGA 与资源说明。
- 检查结果：Lua 5.0.3 编译及运行通过，574 项检查通过，其中 528 组完整布局覆盖四类物品、10–20 全部字号、左右两侧各首/中/尾位置、中心位置模块显示/隐藏。读取现用其他模块的实际文字构造代码及完整 Gold.lua，解析多锚点、FontString 范围和按钮边界，检查所有信息栏文字的中心线、字号、金币图标中心、模块间距、传送图标留位及可见区域与点击范围，包含三种缩放坐标检查。保留字体 SetFont 失败和原有物品行为回归；资源生成器 `--check` 通过，四张贴图 Alpha>=128 的可见区域中心均为 (16,16)，透明 32 位未压缩 TGA 与 SVG/几何源一致。
- 游戏验收与未确认：通过 Windows-MCP 查看了修复前的当前游戏信息栏；本条修复后未进行游戏内验收。几何模拟的字体尺寸与缩放模型不是客户端实际字形栅格化，不能据此宣称真实画面已对齐。需完整退出游戏重新进入后，检查时光沙漏及另外三种图标、文字与其他模块的显示和点击范围。
- 关联或替代关系：替代 `diminfo-20261030-02` 的固定高度按钮/固定偏移布局及 `diminfo-20261030-03` 未统一的图案留白，保留其图标风格与传送交互。历史记录和原始验证结论保持原样。

### 2026-10-30｜传送按钮改用统一的原创线条图标

- 记录编号：`diminfo-20261030-03`
- 记录类型：修改
- 游戏验收：待游戏验收
- 对应提交：随本条记录一并提交（见本页 Git 历史）

- 修改原因：用户认为直接使用物品原图及自带的方形边框不符合信息条风格，希望重构为统一的新图标。

- 涉及文件：`Modules/Teleport.lua`、`tests/teleport.lua`、新增 `Media/Teleport/` 下四组 `.svg`/`.tga` 和资源说明、`tools/render_teleport_icons.py`。
- 检查结果：Lua 5.0.3 编译通过，完整传送回归 46 项通过；新增覆盖四类自带图标路径、缺失时符号保留、图文状态同步染色，并使 GetInventoryItemTexture 在测试中直接报错，确认已装备物品也不读取原图。资源生成器 `--check` 通过，四组 SVG/TGA 与几何源一致；贴图为旧客户端使用的 32 位未压缩 TGA、8 位 Alpha、32×32 二次幂尺寸，透明角落及 Alpha 范围检查通过。已查看大图与接近游戏大小的预览，线条和透明背景正常。
- 游戏验收与未确认：没有进行修复后游戏内实测；新增贴图需在客户端确认，若 `/reload` 后未显示，完整退出并重新启动游戏后检查。离线预览和接口模拟不能替代真实游戏验收。
- 关联或替代关系：替代 `diminfo-20261030-01` 的物品原图显示方式，保留 `diminfo-20261030-02` 的对齐修正和既有交互；两条历史记录保持原样。
