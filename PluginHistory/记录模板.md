# 插件记录模板

[记录规范](记录规范.md) · [插件分类](Plugins/README.md)

每个插件一份页面，在“逐次修改记录”顶部追加真实条目。下面字段按实际情况填写；无关联或替代关系就省略相应行。

```markdown
<a id="change-插件名-YYYYMMDD-01"></a>

### YYYY-MM-DD｜本次变化

- 记录编号：`插件名-YYYYMMDD-01`
- 记录类型：修改
- 游戏验收：待游戏验收
- 对应提交：随本条记录一并提交（见本页 Git 历史）

- 修改原因：真实问题或需求。
- 修改内容：实际发生的变化，未实施则明确说明。
- 涉及文件：真实相关文件。
- 检查结果：实际运行的检查及结果，未测范围如实说明。
- 关联或替代关系：仅在存在时填写。
```

页面保持“插件概况 → 当前维护摘要 → 可选的目前存在的问题／进一步优化方案 → 逐次修改记录 → 早期历史汇总与维护依据”。问题与优化方案**不是必填项**，只在确实存在或已经提出时新增，附原记录/讨论依据。不要生成占位问题、默认计划或把旧待补充项自动转成当前任务。

日期不明的旧记录留在早期汇总，原始文字与证据可折叠展示。DLL 等组件使用 Runtime 下独立页面。
